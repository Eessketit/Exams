Question 1 · Open question · Lecture 2.1, Multivariate and polynomial regression

Gradient descent, the normal equation and polynomial regression

  1. (a)Write the vectorized gradient descent update and the normal equation for multivariate linear regression.
  2. (b)Compare the two methods (the four points of the comparison table).
  3. (c)How can linear regression fit a curved relationship? Why is polynomial regression still a linear model, and what is its main hyperparameter?

(a) What to write

  • Loss: J(θ) = (1/2m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)², with h = Xθ and x₀ = 1 for every example.
  • Gradient descent (repeat): θ := θ − α · (1/m) · Xᵀ(Xθ − y). All θj are updated simultaneously.
  • Normal equation (one step): θ = (XᵀX)⁻¹ · Xᵀy.
  • Shapes: X is m × (n + 1) with the column of 1s first, θ is (n + 1) × 1 and y is m × 1.
  • The link between them: setting the gradient (1/m)Xᵀ(Xθ − y) to 0 gives XᵀXθ = Xᵀy, which the normal equation solves directly.
J(θ) = (1/2m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)²        h = Xθ,  x₀ = 1
gradient descent, repeat:   θ := θ − α · (1/m) · Xᵀ(Xθ − y)
normal equation, once:      θ = (XᵀX)⁻¹ · Xᵀy

(b) The comparison table (slide 42)

Gradient descentNormal equation
Need to choose the learning rate αNo need to choose α
Needs many iterationsNo iterations
Works well even when the number of features is very largeVery slow when the number of features is very large
Needs to compute (XᵀX)⁻¹
  • Rule of thumb: few features (n = 3), use the normal equation, which is exact and fast. Very many features (n = 10⁶), use gradient descent.
  • Why: inverting an (n + 1) × (n + 1) matrix costs about n³ operations (textbook context), while one gradient descent step grows only linearly in n.

(c) What to write

  • On curved data a straight line y = ax + b underfits. Construct new features from x (x², x³, ...) and train a standard linear regression on them: h = w₁x + w₂x² + w₃x³ + b.
  • The model is still linear in the parameters w. "Polynomial" refers only to the shape of the features, so the gradient descent update and the normal equation work unchanged with X columns [1, x, x², x³].
  • In code: make_pipeline(PolynomialFeatures(degree=2), LinearRegression()). The main hyperparameter is the degree. Too low underfits, too high overfits.
PolynomialFeatures(degree=3):   x = 2  →  [1, x, x², x³] = [1, 2, 4, 8]
h = b·1 + w₁·x + w₂·x² + w₃·x³    a weighted sum of columns, linear in w
Exam line

Gradient descent repeats θ := θ − α(1/m)Xᵀ(Xθ − y). It needs α and many iterations, and works well with very many features. The normal equation θ = (XᵀX)⁻¹Xᵀy needs no α and no iterations, but is very slow when the number of features is very large. Polynomial regression constructs x², x³, ... as new features and stays linear in w; the degree is its main hyperparameter.

Question 2 · Open question · Lecture 3.2, Naive Bayes

Naive Bayes classifier

  1. (a)State Bayes theorem and explain each term. In the classifier, what are A and B?
  2. (b)What is the "naive" assumption, and how does it change the formula for P(class | x₁, ..., xₙ)? How is the class decided?
  3. (c)Give three advantages and three disadvantages of Naive Bayes.

(a) What to write

P(A | B) = P(B | A) · P(A) / P(B)

  • P(A | B): probability of A given B (the posterior). P(B | A): probability of B given A (the likelihood). P(A), P(B): the probabilities of the events (prior and evidence).
  • Bayes theorem gives the probability of an event from prior knowledge of conditions related to it.
  • In the classifier: A = the class (Buy / No Buy), B = the features (Day, Discount, Free Delivery).

(b) What to write

  • Naive assumption: the features are independent of each other given the class. So P(x₁, ..., xₙ | A) = P(x₁ | A) · P(x₂ | A) · ... · P(xₙ | A).
  • Posterior (lecture form): P(A | x₁, ..., xₙ) = P(x₁ | A) ⋯ P(xₙ | A) · P(A) / (P(x₁) ⋯ P(xₙ)).
  • Compute it for every class, normalize the values so they add up to 1, and pick the class with the larger value. The denominator is the same for every class, so the decision is the same as argmax P(A) Π P(xᵢ | A).

Result: Buy 0.192 vs No Buy 0.0213, normalized 90 % vs 10 %, so the customer buys.

(c) What to write

Advantages (slide 27)Disadvantages (slide 28)

Handles continuous and discrete dataPoor probability calibration: use the scores to rank, not as true confidence
Highly scalable; fast, so good for real-time predictionBiased toward the majority class on imbalanced data
Not sensitive to irrelevant features
  • Figure 2 shows "needs less training data": 7 counts per class are well filled by 15 rows, 12 joint counts are not.
  • Figure 3 shows the calibration point: the slide's two scores add up to 1.09 before normalizing, so they are not true probabilities.
Exam line

P(A | B) = P(B | A) P(A) / P(B), with A = the class and B = the features. Naive: the features are independent given the class, so P(B | A) = P(x₁ | A) ⋯ P(xₙ | A). Compute the score for every class, normalize, and pick the largest.

Question 3 · Open question · Lecture 5.2, Data preparation

Missing values and outliers

  1. (a)Name and explain the three mechanisms of missing data, with an example of each.
  2. (b)List the methods for handling missing values and when each is used.
  3. (c)Explain the IQR rule and the Z-score rule for detecting outliers. Apply both to the data 2, 4, 4, 5, 6, 7, 8, 8, 30 (Q1 = 4, Q3 = 8, μ = 8.22, σ = 7.93).

(a) What to write

MechanismMeaningSlide example
MCAR, Missing Completely At Randomnot related to any variablea sensor briefly went offline
MAR, Missing At Randomrelated to other observed variablesolder respondents skip income questions
MNAR, Missing Not At Randomdepends on the missing value itself (hardest)high earners hide their income

(b) What to write

MethodCodeUse

KNN ImputerKNNImputerfill from the nearest neighbours
Iterative ImputerIterativeImputer (MICE)predict each missing value from the other columns
  • Diagnose the mechanism first. Dropping every row with a missing value is a common mistake.

(c) Worked solution

  • IQR rule ("robust, distribution-free"): IQR = Q3 − Q1, lower bound = Q1 − 1.5·IQR, upper bound = Q3 + 1.5·IQR. Values outside the bounds are outliers.
  • Z-score rule: z = (x − μ)/σ, and |z| > 3 is an outlier. It assumes roughly normal data.
IQR = 8 − 4 = 4          1.5 · IQR = 6
bounds = [4 − 6, 8 + 6] = [−2, 14]      30 > 14   → outlier
z(30) = (30 − 8.22) / 7.93 = 2.75       2.75 < 3  → not flagged
same rule in data units: μ ± 3σ = 8.22 ± 23.78 = [−15.56, 32.00]
  • IQR flags 30 as an outlier. The Z-score rule does not flag 30, because the outlier itself inflates μ and σ (masking).
  • Extra check: with only 9 values and the population σ, no |z| can be larger than √(9 − 1) = 2.83, so |z| > 3 cannot flag anything in this data set.
  • That is why the slide says to "combine with IQR when in doubt". After detection, decide whether to fix, cap or keep the outlier. ML-based detectors: Isolation Forest, Local Outlier Factor, autoencoders.

Result: IQR bounds [−2, 14], 30 is an outlier; z(30) = 2.75 < 3, not flagged.

Exam line

MCAR: not related to any variable. MAR: related to other observed variables. MNAR: depends on the missing value itself. IQR rule: outside [Q1 − 1.5·IQR, Q3 + 1.5·IQR], robust. Z-score rule: |z| > 3, assumes normal data and can be masked by the outlier, so "combine with IQR when in doubt".

Question 4 · Problem · Lecture 2.1, Gradient descent and normal equation

Linear regression: gradient descent and normal equation

Data: x = [1, 2, 4], y = [3, 5, 9]. Model hθ(x) = θ₀ + θ₁x. Start at θ = [0, 0]ᵀ with α = 0.05.

  1. (a)Write X (with x₀) and compute the loss J(θ) = (1/2m) Σ(h − y)² at the start.
  2. (b)Do one gradient descent update and give the new θ.
  3. (c)Compute J at the new θ.
  4. (d)Solve the same problem with the normal equation and predict y for x = 5.

(a) Worked solution

X = [[1, 1],      y = [3, 5, 9]ᵀ      m = 3
     [1, 2],
     [1, 4]]
θ = [0, 0]:  h = Xθ = [0, 0, 0],   h − y = [−3, −5, −9]
J = (9 + 25 + 81) / (2 × 3) = 115 / 6 = 19.167

(b) Worked solution

Xᵀ(h − y) = [−3 − 5 − 9,  −3 − 10 − 36] = [−17, −49]
(1/m)Xᵀ(h − y) = [−5.667, −16.333]
θ = [0, 0] − 0.05 · [−5.667, −16.333] = [0.2833, 0.8167]

Result: θ = [0.2833, 0.8167]

(c) Worked solution

h = 0.2833 + 0.8167x = [1.100, 1.917, 3.550]
h − y = [−1.900, −3.083, −5.450]
J = (3.610 + 9.507 + 29.703) / 6 = 42.819 / 6 = 7.137

Result: J = 7.137. The loss fell from 19.167 to 7.137 in one step.

(d) Normal equation

XᵀX = [[3, 7], [7, 21]]        (m, Σx; Σx, Σx²)
det = 3 · 21 − 7 · 7 = 63 − 49 = 14
(XᵀX)⁻¹ = (1/14) [[21, −7], [−7, 3]]
Xᵀy = [Σy, Σxy] = [17, 3 + 10 + 36] = [17, 49]
θ = (1/14) [21·17 − 7·49, −7·17 + 3·49] = (1/14) [14, 28] = [1, 2]
h = 1 + 2x,   x = 5:  1 + 2·5 = 11
  • θ = [1, 2], so h = 1 + 2x. It fits all three points exactly (J = 0).
  • Gradient descent would reach [1, 2] only after many iterations (Figure 2); the normal equation gets it in one step, with no α.

Result: θ = [1, 2], h = 1 + 2x, prediction for x = 5 is 11.

Exam line

Add x₀ = 1 as the first column of X. One step: θ := θ − α(1/m)Xᵀ(Xθ − y), here [0.2833, 0.8167], and J falls from 19.167 to 7.137. Normal equation: θ = (XᵀX)⁻¹Xᵀy = [1, 2], so h(5) = 11.

Question 5 · Problem · Lecture 3.2, K-nearest neighbours

K-nearest neighbours

Eight training points of classes A and B. Query point Q = (3, 3).

  1. (a)Compute the Euclidean distance from Q to every point and rank them.
  2. (b)Classify Q with k = 1, k = 3 and k = 5.
  3. (c)Repeat the k = 3 classification with the Manhattan distance. Does the answer change?
  4. (d)A test of k gives these error rates: k = 1: 0.30, k = 3: 0.22, k = 5: 0.18, k = 7: 0.17, k = 9: 0.17. Which k should be chosen, and why?

(a) Worked solution

d = √((x1 − 3)² + (x2 − 3)²)

(b) Worked solution

  • k = 1: nearest is P4 (A), so A.
  • k = 3: P4 (A), P5 (B), P7 (B): 2 B vs 1 A, so B.
  • k = 5: add P2 (A) and P1 (A): 3 A vs 2 B, so A.
  • The prediction depends on k (as in the slide 47 star example).

Result: k = 1 → A, k = 3 → B, k = 5 → A.

(c) Worked solution

  • Manhattan |x1 − 3| + |x2 − 3|: the three smallest are P4 (2, A), P5 (2, B) and P2 (3, A). Vote 2 A vs 1 B, so A.
  • The answer changes from B to A. P7 is close in a straight line (2.83) but 4 blocks away on the grid, and P2 replaces it.

Result: Manhattan, k = 3 → A. The answer changes.

(d) What to write

  • Choose k = 5, the elbow point. The error drops quickly from k = 1 to k = 5 (0.30 to 0.18), then almost stops improving (0.17).
  • Very small k overfits. Larger k smooths and costs more computation without gaining accuracy.
Exam line

KNN: compute the distance from the query to every training point, rank them, and take the majority class of the k nearest. The answer depends on k and on the distance measure. Choose k at the elbow of the error rate, here k = 5.

Question 6 · Problem · Lecture 4.1, Decision tree

Decision tree with ID3

Will a customer wait for a table at a restaurant?

  1. (a)Compute the entropy of the dataset.
  2. (b)Compute the information gain of Patrons, Hungry and Price, and choose the root.
  3. (c)Which branches become leaves right away? Finish the tree.
  4. (d)Predict Wait for {Full, Hungry = No, Cheap} and for {Some, Hungry = No, Expensive}.

(a) Worked solution

7 Yes, 5 No out of 12
E(S) = −(7/12) log₂(7/12) − (5/12) log₂(5/12)
     = 0.5833 · 0.7776 + 0.4167 · 1.2630
     = 0.4536 + 0.5263 = 0.980

Result: E(S) = 0.980

(b) Root

IG(S, a) = E(S) − Σv |Sv| / |S| · E(Sv)

AttributeValue: Yes/No (entropy)Weighted EIG
PatronsNone 0/3 (0), Some 4/0 (0), Full 3/2 (0.971)5/12 · 0.971 = 0.4050.575
HungryYes 5/2 (0.863), No 2/3 (0.971)7/12 · 0.863 + 5/12 · 0.971 = 0.9080.072
PriceCheap 4/2 (0.918), Expensive 3/3 (1)0.9590.021

Result: Patrons has by far the largest IG (0.575) and becomes the root.

(c) Leaves and the rest of the tree

  • None (0/3) is pure, so it becomes a No leaf. Some (4/0) is pure, so it becomes a Yes leaf.
  • Full (rows 6, 7, 8, 9, 11: 3 Yes / 2 No, E = 0.971) needs another split.
  • Inside Full: Hungry gives Yes 3/0 and No 0/2, IG = 0.971 (perfect). Price gives Cheap 2/1 (0.918) and Expensive 1/1 (1), weighted 0.951, IG = 0.020. Split on Hungry.
  • Price is never used.

(d) Predictions

  • {Full, Hungry = No, Cheap}: Patrons = Full, then Hungry = No, so No.
  • {Some, Hungry = No, Expensive}: Patrons = Some, so Yes (no more questions).

Result: No, and Yes.

Exam line

E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋. IG = E(S) − Σ |Sᵥ|/|S| · E(Sᵥ); the attribute with the highest IG becomes the node. A pure node becomes a leaf. Here Patrons (IG 0.575) is the root, None and Some are leaves, and Full splits on Hungry.
