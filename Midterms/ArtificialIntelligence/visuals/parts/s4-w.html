Question 1 · Open question · Lecture 2.2, Logistic regression

Logistic regression

  1. (a)Why does linear regression fail for classification? Use the tumour-size example.
  2. (b)Write the hypothesis of logistic regression and explain how its output is interpreted and how it gives a decision boundary.
  3. (c)Write the cost function of logistic regression. Why is the squared-error cost of linear regression not used?

(a) What to write

  • Fit a straight line hθ(x) = Xθ to tumour size vs malignant (0/1) and predict y = 1 when h ≥ 0.5.
  • On clean data the 0.5 crossing separates the classes. Add one very large malignant tumour far to the right. The least-squares line flattens, its 0.5 crossing moves right, and some malignant tumours are now predicted benign. One correct but extreme example ruins the classifier.
  • Also, y is 0 or 1, but a straight line can output values > 1 or < 0. Logistic regression keeps 0 ≤ hθ(x) ≤ 1.

(b) Hypothesis, probability, decision boundary

hθ(x) = g(θᵀx),   g(z) = 1 / (1 + e⁻ᶻ)   (sigmoid / logistic function)

  • g(0) = 0.5, g → 1 as z → ∞, g → 0 as z → −∞. So the output always stays between 0 and 1.
  • Interpretation: hθ(x) = P(y = 1 | x; θ). If h = 0.7, tell the patient there is a 70% chance the tumour is malignant. P(y = 0 | x; θ) = 1 − 0.7 = 0.3.
  • Decision: predict y = 1 if h ≥ 0.5. This happens exactly when θᵀx ≥ 0, so the decision boundary is θᵀx = 0.
  • Example θ = [−3, 1, 1]: predict 1 when x₁ + x₂ ≥ 3, so the boundary is the line x₁ + x₂ = 3. Polynomial features (x₁², x₂², ...) give a curved boundary.

(c) Cost function

Cost(h, y) = −log(hθ(x))        if y = 1
             −log(1 − hθ(x))    if y = 0
           = −y log h − (1 − y) log(1 − h)

J(θ) = −(1/m) Σ [ y⁽ⁱ⁾ log hθ(x⁽ⁱ⁾) + (1 − y⁽ⁱ⁾) log(1 − hθ(x⁽ⁱ⁾)) ]
  • A confident wrong answer is punished hard. For y = 1 the cost → ∞ as h → 0, and it is 0 at h = 1.
  • Why not MSE (textbook context): with the sigmoid inside, (h − y)² gives a non-convex J with flat regions and local minima, so gradient descent can get stuck. The log loss is convex, with one global minimum.
Exam line

hθ(x) = g(θᵀx) with g(z) = 1/(1 + e⁻ᶻ) is the probability P(y = 1 | x; θ). Predict 1 when h ≥ 0.5, which is θᵀx ≥ 0, so the decision boundary is θᵀx = 0. Cost = −y log h − (1 − y) log(1 − h): convex, while squared error with a sigmoid is non-convex.

Question 2 · Open question · Lecture 3.2, K-nearest neighbours

K-nearest neighbours

  1. (a)Describe the KNN algorithm for classification and for regression. Why is it called lazy and non-parametric?
  2. (b)Give the Euclidean, Manhattan and Minkowski distances, and when each is used.
  3. (c)How is k chosen, and what happens when k is very small or very large? Give the advantages and limitations of KNN.

(a) The algorithm

1. choose k and a distance function
2. compute the distance from the new point to every training point
3. rank the distances and take the k closest points
4. classification: the most frequent label among the k neighbours
   regression:     the average of their values
  • Assumption: similar data points lie close together.
  • Non-parametric: it learns no parameters, it memorizes the training set. Lazy: no modelling at training time. All the work happens at prediction time.

(b) Distance measures

DistanceFormulaUse
Euclidean√((x₂ − x₁)² + (y₂ − y₁)²)straight line; continuous features (height, salary); the default
ManhattanΣ |xᵢ − yᵢ|grid-like paths; integer features
Minkowski(Σ |xᵢ − yᵢ|ᵖ)1/pgeneral form: p = 1 Manhattan, p = 2 Euclidean

(c) Choosing k, pros and cons

  • Split the data into train and test, try different k, and plot the error rate against k. Choose the elbow, where a larger k barely lowers the error (k = 5 on slide 49).
  • Small k (k = 1) follows single noisy points, so it overfits. Large k smooths the prediction; k = N always predicts the majority class.
  • Advantages: simple, adaptable (new samples are used at once), easy to program (only k and a distance metric to set).
  • Limitations: difficult to scale (stores all the data and scans it for every prediction), curse of dimensionality (distances grow with the number of dimensions), overfitting with small k.
Exam line

KNN: compute the distance to every training point, take the k closest, then the majority label (classification) or the average (regression). Non-parametric because it learns no parameters, lazy because all the work happens at prediction time. Choose k at the elbow of error rate vs k; small k overfits.

Question 3 · Open question · Lecture 4.2, Support vector machine

Kernels in SVM

  1. (a)When is a linear SVM enough, and when is a non-linear SVM needed? Explain the idea of a kernel with an example.
  2. (b)Name the kernels from the lecture with their formulas and hyperparameters.
  3. (c)List the advantages and disadvantages of SVM.

(a) Linear vs non-linear, and the kernel idea

  • Linear SVM: the data is linearly separable, so one straight line (hyperplane) splits the two classes.
  • Non-linear SVM: no straight line separates them, e.g. 1D data green-red-green, or a green disk inside a red ring (slide 44).
  • Kernel idea: map the data to a higher dimension where a hyperplane does separate the classes.
  • Example: points x = −3 ... 3, class + when |x| ≥ 2. No threshold on x works, but with φ(x) = x² the values become 9, 4, 1, 0, 1, 4, 9, and x² = 2.5 separates the classes.
  • In 2D, adding x₁² + x₂² lifts the inner disk below the ring, and a flat plane cuts them apart (slide 46).
  • Kernel trick (textbook context): the SVM needs only dot products, so K(xi, xj) gives φ(xi)·φ(xj) directly, without ever computing φ.
kernel trick with the slide-47 polynomial kernel, d = 2, in 1D:
K(x, z) = (x·z + 1)² = 1 + 2xz + x²z² = φ(x)·φ(z),   φ(x) = (1, √2·x, x²)
x = 2, z = 3:  K = (6 + 1)² = 49
               φ(2)·φ(3) = 1·1 + 2.828·4.243 + 4·9 = 1 + 12 + 36 = 49

Question 4 · Problem · Lecture 3.1, Evaluating learning algorithms

Evaluating a classifier and a regressor

  1. (a)A classifier is tested on 12 examples (1 = positive). Build the confusion matrix and compute accuracy, precision, recall and F1.
  1. (b)A regression model predicts h = [2.5, 5.5, 7, 8, 12] for the targets y = [3, 5, 7, 9, 11]. Compute MSE, RMSE, MAE and R².

(a) Confusion matrix

  • Label each example. The second word is what the model predicted; the first says whether it was right.
  • TP = 4, FN = 2, FP = 1, TN = 5 (total 12).
Accuracy  = (TP + TN) / total = (4 + 5) / 12  = 75%
Precision = TP / (TP + FP)    = 4 / (4 + 1)   = 0.80
Recall    = TP / (TP + FN)    = 4 / (4 + 2)   = 0.667
F1        = 2 · P · R / (P + R) = 2 · 0.8 · 0.667 / (0.8 + 0.667) = 0.727

Result: accuracy 75%, precision 0.80, recall 0.667, F1 0.727. The model raises few false alarms (high precision) but misses a third of the positives (lower recall).

Question 5 · Problem · Lecture 6.1, K-Means clustering

K-Means++ and the elbow method

Points A(1, 2), B(2, 1), C(5, 4), D(6, 5), E(9, 8). Use squared Euclidean distance.

  1. (a)K-Means++ picks C(5, 4) as the first centroid. Compute D(x)² for every point and the probability of each point becoming the second centroid.
  2. (b)Suppose the second centroid is E. Run K-Means with K = 2 from centroids C and E until convergence. Give the clusters and J.
  3. (c)Repeat (b) with the second centroid A instead. Which result is better, and what does this show?
  4. (d)The best possible J for K = 1 to 5 is 71.2, 18.33, 2.0, 1.0 and 0. Which K does the elbow method choose?

(a) D(x)² and the sampling probabilities

PointD(x)² to C(5, 4)Probability
A (1, 2)16 + 4 = 2020/72 = 0.278
B (2, 1)9 + 9 = 1818/72 = 0.250

Result: E is the most likely second centroid (0.444), A the second most likely (0.278).

(b) K-Means from C and E

  • Iteration 1 (squared distances to C / to E): A 20 / 100, B 18 / 98, C 0 / 32, D 2 / 18, E 32 / 0. Clusters {A, B, C, D} and {E}.
  • New centroids: (14/4, 12/4) = (3.5, 3) and (9, 8).
  • Iteration 2: A 7.25 / 100, B 6.25 / 98, C 3.25 / 32, D 10.25 / 18, so nothing changes. Converged.
  • J = 7.25 + 6.25 + 3.25 + 10.25 + 0 = 27.

Result: clusters {A, B, C, D} and {E}, J = 27.

(c) K-Means from C and A

  • Iteration 1: A and B go to A (0 and 2 vs 20 and 18); C, D, E go to C (0, 2, 32 vs 20, 34, 100). Clusters {A, B} and {C, D, E}.
  • New centroids: (1.5, 1.5) and (6.667, 5.667). Iteration 2: no change, so converged.
  • J = (0.5 + 0.5) + (5.556 + 0.889 + 10.889) = 18.33.
  • (c) is better (18.33 < 27). K-Means only finds a local minimum, and the result depends on the initial centroids. K-Means++ makes good starts likely but not certain. In practice K-Means is run several times and the lowest J is kept (textbook context).

Result: clusters {A, B} and {C, D, E}, J = 18.33 < 27, so (c) is better.

(d) Elbow method

  • The drops are 71.2 → 18.33 (−52.9), → 2.0 (−16.3), → 1.0 (−1.0), → 0 (−1.0).
  • After K = 3 the curve flattens, so the elbow is K = 3: clusters {A, B}, {C, D}, {E}.

Result: K = 3, clusters {A, B}, {C, D}, {E}.

Exam line

K-Means++: choose the first centroid at random, then pick each next centroid with probability proportional to D(x)², the squared distance to the nearest chosen centroid. K-Means converges only to a local minimum that depends on the start. Elbow method: plot J (inertia) against K and choose the K where the decrease levels off.

Question 6 · Problem · Lecture 4.1, Decision tree

Decision tree with ID3

Is an email spam?

  1. (a)Compute the entropy of the dataset and the information gain of each attribute. Choose the root.
  2. (b)Find the best attribute for the impure branch of the root, and continue until all leaves are pure.
  3. (c)Draw the final tree.
  4. (d)Classify {Link = No, Known = No, Attachment = Yes} and {Link = Yes, Known = Yes, Attachment = Yes}.

(a) Root

E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋   ·   IG(S, a) = E(S) − Σv (|Sv| / |S|) · E(Sv)

5 Yes, 7 No:  E(S) = −(5/12) log₂(5/12) − (7/12) log₂(7/12) = 0.980
AttributeValue: Yes/No (entropy)Weighted EIG
KnownNo 5/2 (0.863), Yes 0/5 (0)7/12 · 0.863 = 0.5030.476
LinkYes 4/2 (0.918), No 1/5 (0.650)0.7840.196
AttachmentNo 2/5 (0.863), Yes 3/2 (0.971)0.9080.072

Result: Known sender is the root. Known = Yes is pure (0/5), so it becomes a No leaf.

(b) Impure branches

  • Branch Known = No (rows 1, 2, 4, 6, 7, 10, 11: 5 Yes / 2 No, E = 0.863):
    • Link: Yes 4/0 (0), No 1/2 (0.918); weighted 3/7 · 0.918 = 0.394; IG = 0.470.
    • Attachment: No 2/2 (1), Yes 3/0 (0); weighted 4/7 · 1 = 0.571; IG = 0.292.
    • Split on Link. Both attributes give one pure child, but Link's pure child is bigger (4 rows vs 3) and its impure child smaller, so it removes more entropy.
  • Branch Known = No, Link = No (rows 4, 7, 10: 1 Yes / 2 No, E = 0.918):
    • Attachment: No 0/2, Yes 1/0, IG = 0.918 (perfect). Split on Attachment.

(c) Final tree and (d) classification

Known [Yes=5, No=7]
|- Yes -> No [0/5]
|- No  -> Link [Yes=5, No=2]
            |- Yes -> Yes [4/0]
            |- No  -> Attachment [Yes=1, No=2]
                        |- Yes -> Yes [1/0]
                        |- No  -> No  [0/2]
  • {Link = No, Known = No, Attachment = Yes}: Known = No, then Link = No, then Attachment = Yes, so Spam.
  • {Link = Yes, Known = Yes, Attachment = Yes}: Known = Yes, so Not spam. One question is enough.
Exam line

ID3: at each node compute E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋ and IG = E(S) − Σ (|Sv|/|S|) E(Sv), split on the attribute with the highest IG, and stop when a node is pure: "when purity is 100%, we make it a leaf node".
