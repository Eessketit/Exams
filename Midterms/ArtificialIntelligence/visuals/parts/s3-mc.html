Question 1 · Lecture 2.1, Polynomial regression

PolynomialFeatures(degree=3) is applied to a single input x = 2. Which feature vector does it produce?

  1. a [2, 4, 6] No. These are 2·1, 2·2, 2·3, multiples of x. The features are powers of x.
  2. b [1, 2, 3] No. 1, 2, 3 are the powers themselves. The features are x raised to them.
  3. c [2, 4, 8] No. These are x, x², x³, but the bias column x⁰ = 1 is missing.
  4. d [1, 2, 4, 8] Correct. [x⁰, x¹, x², x³] = [1, 2, 4, 8].

Answer: d. PolynomialFeatures builds the columns [1, x, x², x³] from the single input x. For x = 2 that is [1, 2, 4, 8]. The 1 is the bias column, x⁰.

A standard linear regression is then trained on these columns. The model h = b + w₁x + w₂x² + w₃x³ has one weight per column, so polynomial regression is still linear in the weights.

Exam line

Polynomial regression constructs new features x², x³, ... from x and trains a standard linear regression on them. PolynomialFeatures turns x into [1, x, x², x³]. The model is still linear in the weights, and degree is the main hyperparameter.

Question 2 · Lecture 2.2, Multiclass classification

A one-vs-all logistic regression is used for a problem with 4 classes. How does it work?

  1. a It trains 4 binary classifiers, each class against all the others, and predicts the class with the largest hθ⁽ⁱ⁾(x) Correct. K classes need K classifiers, and the largest output wins.
  2. b It trains 1 classifier whose output is rounded to 1, 2, 3 or 4 No. A logistic regression outputs one probability between 0 and 1 for one yes/no question.
  3. c It trains 6 classifiers, one per pair of classes, and takes a vote No. That is one-vs-one, 4·3/2 = 6 pairs. It is not in the lecture.
  4. d It trains 3 classifiers and predicts the class with the smallest hθ⁽ⁱ⁾(x) No. 4 classes need 4 classifiers, and the smallest output is the class x looks least like.

Answer: a. For each class i, one-vs-all treats class i as positive and all the other classes as negative. It trains hθ⁽ⁱ⁾(x) = P(y = i | x; θ), so 4 classes give 4 binary classifiers.

On a new input x it runs all four and picks the class i that maximizes hθ⁽ⁱ⁾(x).

4 classes have 4·3/2 = 6 pairs. One-vs-all needs only 4 classifiers.

Question 3 · Lecture 3.1, Regression metrics

A regression model makes errors of 1, 1, 1, 1 and 6 on five test examples. What is the MSE?

  1. a 2 No. 2 is the MAE, (1 + 1 + 1 + 1 + 6)/5.
  2. b 8 Correct. (1 + 1 + 1 + 1 + 36)/5 = 40/5 = 8.
  3. c 2.83 No. 2.83 = √8 is the RMSE.
  4. d 40 No. 40 is the sum of the squared errors before dividing by m = 5.

Answer: b. MSE = (1/m) • Σ (hθ(x)⁽ⁱ⁾ − y⁽ⁱ⁾)². Square each error, add the squares and divide by m = 5: (1 + 1 + 1 + 1 + 36)/5 = 40/5 = 8.

The single error of 6 contributes 36 of the 40. That is why the slide calls MSE sensitive to large errors. MAE = 2 is less sensitive, and RMSE = √8 = 2.83 is in the units of the target.

Exam line

MSE = (1/m) • Σ(hθ(x)⁽ⁱ⁾ − y⁽ⁱ⁾)², sensitive to large errors. RMSE = √MSE, in the units of the target. MAE = (1/m) • Σ|hθ(x)⁽ⁱ⁾ − y⁽ⁱ⁾|, less sensitive to large errors. Errors 1, 1, 1, 1, 6 give MSE 8, RMSE 2.83, MAE 2.

Question 4 · Lecture 3.2, KNN

Why is KNN called a "lazy" learner?

  1. a It needs only a few training examples No. It keeps every example it gets, and more examples make each prediction slower.
  2. b It always uses k = 1 No. k is chosen by the user, for example at the elbow of the error rate.
  3. c It stores the whole training set and does no modelling; all the distance computation happens at prediction time Correct. fit only stores X_train and y_train.
  4. d It learns its weights slowly with a small learning rate No. KNN learns no weights at all. It is non-parametric.

Answer: c. KNN has no training phase. fit only stores X_train and y_train. Each prediction computes the distance from the new point to every training point, ranks them and lets the k nearest vote.

KNN is also non-parametric, which means it learns no parameters and memorizes the training set. Because all the work waits for prediction time, it is difficult to scale to big data.

Exam line

KNN is a lazy learner. It stores the whole dataset and does no modelling, and all the distance computation happens at prediction time. It is non-parametric: it learns no parameters and memorizes the training set. That makes it difficult to scale.

Question 5 · Lecture 4.1, Information gain

A node with 6 Yes and 4 No (entropy 0.971) is split into two children: 4 Yes / 0 No and 2 Yes / 4 No (entropy 0.918). What is the information gain of this split?

  1. a 0.420 Correct. 0.971 − (4/10 · 0 + 6/10 · 0.918) = 0.971 − 0.551 = 0.420.
  2. b 0.551 No. 0.551 is the weighted child entropy E(Y | X). IG subtracts it from the parent's entropy.
  3. c 0.971 No. IG = 0.971 would need both children pure. The 2 Yes / 4 No child is still mixed.
  4. d 0.053 No. 0.971 − 0.918 forgets the weights and ignores the pure child.

Answer: a. IG = E(Y) − E(Y | X), and each child's entropy is weighted by its share of the rows. The pure child holds 4 of the 10 rows with entropy 0. The mixed child holds 6 of the 10 with entropy 0.918.

E(Y | X) = (4/10)·0 + (6/10)·0.918 = 0.551, so IG = 0.971 − 0.551 = 0.420.

Exam line

IG(S, a) = Entropy(S) − Σ |Sᵥ|/|S| · Entropy(Sᵥ). Weight each child by its share of the rows: 0.971 − (6/10) × 0.918 = 0.420. The attribute with the highest IG becomes the node.

Question 6 · Lecture 4.2, Hard margin SVM

A linear SVM has the weight vector w = (3, 4). What is the width d of its margin (the distance between the lines w·x + b = 1 and w·x + b = −1)?

  1. a 0.2 No. 0.2 = 1/‖w‖ is the distance from the hyperplane to one margin line.
  2. b 0.4 Correct. d = 2/‖w‖ = 2/5 = 0.4.
  3. c 2.5 No. 2.5 = ‖w‖/2 turns the fraction upside down.
  4. d 5 No. 5 is ‖w‖ itself, the length of w.

Answer: b. From one margin line to the other, w·x + b changes by 2. Along the direction of w it changes by ‖w‖ per unit of distance. So the lines are d = 2/‖w‖ apart.

Here ‖w‖ = √(3² + 4²) = √25 = 5, so d = 2/5 = 0.4. A smaller ‖w‖ gives a wider margin, which is why SVM minimizes ½‖w‖².

Exam line

Margin lines w·x + b = ±1 are d = 2/‖w‖ apart. SVM maximizes 2/‖w‖, which is the same as minimizing ½‖w‖². For w = (3, 4), ‖w‖ = 5 and d = 0.4.

Question 7 · Lecture 5.2, Categorical encoding

A dataset has a nominal feature City ∈ {Tashkent, Samarkand, Bukhara} with no natural order. Which encoding should be used for a linear model?

  1. a Label encoding (0, 1, 2) No. Label encoding is for ordinal categories. Here it invents an order and distances between the cities.
  2. b Drop the column No. The city carries information about the target, and dropping it throws that away.
  3. c Min-max scaling of the city names No. Scaling works on numbers. City names are text and must be encoded first.
  4. d One-hot encoding (one 0/1 column per city) Correct. Best for nominal categories with a manageable number of values.

Answer: d. One-hot encoding gives each city its own 0/1 column, so a linear model learns one weight per city and no order is implied. With three cities that is only three columns.

Label encoding is for ordinal categories such as small < medium < large. On nominal data it "invents a false numeric relationship" (Bukhara = 2 > Tashkent = 0). A linear model then has a single weight for the code, so the prediction must move in equal steps along that made-up order.

Exam line

Nominal categories with a manageable number of values: one-hot encoding. Ordinal categories (small < medium < large): label encoding. Label-encoding unordered categories invents a false numeric relationship and is a common mistake.

Question 8 · Lecture 5.2, Feature scaling and data leakage

How should a StandardScaler be used with a train/test split?

  1. a Fit it on the whole dataset, then split No. μ and σ then include the test rows, so test information leaks into training.
  2. b Fit it separately on the training set and on the test set No. The test set gets its own μ and σ, so the same raw value is scaled differently in train and test.
  3. c Fit it on the training set only, then transform both the training and the test set with the training mean and std Correct. "Fit the scaler only on training data."
  4. d Fit it on the test set only, so that the test values are exactly standardized No. Fitting a scaler on test data is one of the common mistakes on slide 36.

Answer: c. Split first. Fit the scaler on the training set only, so μ and σ come from training data. Then transform the training set and the test set with that same μ and σ. On the test set call transform() only, never fit() again.

Any fit that sees test rows lets test information leak into training (data leakage). The metrics look great, but the model fails in production.

Exam line

Fit the scaler only on training data. On the test set call transform() only, never fit() again. Fitting on test data, or on the whole dataset before the split, is data leakage: the metrics look great and the model fails in production.

Question 9 · Lecture 6.1, Choosing K

K-Means is run for K = 1 to 6, giving inertia (SSE) values 1000, 400, 150, 120, 100, 90. Using the elbow method, which K should be chosen?

  1. a 3 Correct. The drop shrinks from 250 to 30 after K = 3, so the curve bends there.
  2. b 1 No. One cluster has the highest inertia, and the second cluster still saves 600.
  3. c 6 No. K = 6 has the lowest inertia, but inertia always falls as K grows.
  4. d 2 No. Going to K = 3 still saves 250, so the curve has not flattened yet.

Answer: a. Plot K on the x-axis against the inertia on the y-axis and look for the bend. The drops are 600, 250, 30, 20 and 10. Up to K = 3 each extra cluster removes a lot of inertia. After K = 3 adding clusters barely lowers it, so the elbow is at K = 3.

The lowest inertia is not the goal. Inertia always falls as K grows and reaches 0 when every point is its own cluster.

Exam line

Elbow method: plot K on the x-axis against the inertia on the y-axis and pick the K where the curve bends. After the elbow, extra clusters buy very little reduction in inertia. Inertia always falls as K grows, so the lowest inertia is not the goal.

Question 10 · Lecture 6.2, Principal components

A dataset has 10 variables. How many principal components does PCA produce, and how is the information distributed among them?

  1. a 2, and they share the information equally No. 2 is a common number of components to keep. PCA produces one per variable, with unequal shares.
  2. b 5, one for every pair of variables No. Components are not built from pairs. Each one is a linear combination of all 10 variables.
  3. c 10, and they share the information equally No. The count is right, but PCA squeezes most of the information into the first components.
  4. d 10, with the maximum possible information in the first component, then the maximum remaining in the second, and so on Correct. This is the slide wording.

Answer: d. Principal components are new variables built as linear combinations of the initial variables, and p variables give p components. "10-dimensional data gives you 10 principal components, but PCA tries to put maximum possible information in the first component, then maximum remaining information in the second and so on."

Reducing the dimension means keeping only the first few components and discarding the low-information ones.

Exam line

10-dimensional data gives 10 principal components. PCA puts the maximum possible information in the first component, then the maximum remaining information in the second, and so on. Keep the first few to reduce the dimension.
