Question 1 · Open question · Lecture 2.2, Overfitting and regularization

Overfitting and regularization

  1. (a)Define underfitting and overfitting. Use the housing-price example with hypotheses of increasing polynomial degree, and name the bias/variance term for each case.
  2. (b)Give the two ways to address overfitting from the lecture.
  3. (c)Write the cost function of logistic regression with L2 regularization. What does λ control, and which parameter is not regularized?

(a) What to write

  • Underfitting = poor performance on both training and test data. The model is too simple: θ₀ + θ₁x (a straight line) on curved housing data. This is high bias.
  • Good fit: θ₀ + θ₁x + θ₂x² follows the trend and generalizes.
  • Overfitting = performs well on training data but poorly on test data. With too many features (θ₀ + θ₁x + ... + θ₄x⁴) the hypothesis fits the training set very well, J(θ) ≈ 0, "but fails to generalize to new examples". This is high variance.
  • Logistic version (slide 42): g(θ₀ + θ₁x₁ + θ₂x₂) underfits; adding x₁², x₂², x₁x₂ fits well; many high-order terms give a contorted boundary that overfits.

(b) Two ways (slide 43)

  • 1. Reduce the number of features: select manually which features to keep, or use a model selection algorithm.
  • 2. Regularization: keep all the features but reduce the magnitude of the parameters θj. It works well when there are many features and each contributes a bit to predicting y.

(c) Regularized cost (slide 46)

J(θ) = −(1/m) Σi=1..m [ y(i) log hθ(x(i)) + (1 − y(i)) log(1 − hθ(x(i))) ] + (λ/2m) Σj=1..n θj²

  • λ is the regularization parameter (a hyperparameter). A larger λ pushes the θj toward 0, which gives a simpler model. Too large a λ underfits; λ = 0 is plain logistic regression.
  • The penalty sum starts at j = 1, so θ₀ is not regularized. Its update is the plain one; for j ≥ 1 the gradient gets the extra term (λ/m)θj.
  • L1 (Lasso) penalty: λ Σ|θj|. L2 (Ridge) penalty: λ Σθj².
θ₀ := θ₀ − α (1/m) Σ (hθ(x(i)) − y(i)) x₀(i)
θj := θj − α [ (1/m) Σ (hθ(x(i)) − y(i)) xj(i) + (λ/m) θj ]     j = 1..n
Exam line

Underfit = high bias, poor on training and test data. Overfit = high variance, it "performs well on training data but poorly on test data". Two fixes: reduce the number of features, or regularization. Regularized logistic regression adds (λ/2m) Σj=1..n θj²; the sum starts at j = 1, so θ₀ is not regularized.

Question 2 · Open question · Lecture 4.2, Support vector machine

SVM: hard margin and soft margin

  1. (a)Define the hyperplane, the support vectors and the margin of an SVM.
  2. (b)Write the hard-margin constraints and optimization problem, and show that the margin width is d = 2/‖w‖.
  3. (c)Why do we need a soft margin? Explain the slack variable ζ and the effect of a large and a small C.

(a) What to write

  • Hyperplane: the decision boundary w·x + b = 0 (a line in 2D). Predict y = +1 if w·x + b ≥ 0, else −1.
  • Support vectors: the points closest to the hyperplane. They alone define it.
  • Margin: the distance between the hyperplane and the closest points (the support vectors). SVM picks the hyperplane with the maximum margin.

(b) Hard margin

  • Margin lines: L1: w·x + b = 1 (positive side), L2: w·x + b = −1 (negative side).
  • Constraints: positive points w·x + b ≥ 1, negative points w·x + b ≤ −1. Multiplying by yᵢ (+1 or −1) gives one constraint: yᵢ(w·xᵢ + b) ≥ 1.
  • Margin: take support vectors x₁ (positive) and x₂ (negative) and project x₁ − x₂ on the unit normal w/‖w‖. From w·x₁ = 1 − b and w·x₂ = −1 − b:

d = (w·x₁ − w·x₂)/‖w‖ = ((1 − b) − (−1 − b))/‖w‖ = 2/‖w‖

  • Problem: maximize 2/‖w‖ subject to yᵢ(w·xᵢ + b) ≥ 1, which is the same as minimize ½‖w‖² subject to the same constraints.
w = (0.5, 0.5),  b = −3,  ‖w‖ = √(0.5² + 0.5²) = 0.707
x₁ = (5, 3), positive SV:   w·x₁ = 2.5 + 1.5 = 4 = 1 − b
x₂ = (1, 3), negative SV:   w·x₂ = 0.5 + 1.5 = 2 = −1 − b
d = (w·x₁ − w·x₂)/‖w‖ = (4 − 2)/0.707 = 2.83 = 2/‖w‖
check: ‖x₁ − x₂‖ = 4, but only its part along w counts

(c) Soft margin

  • Real data is rarely perfectly separable, so the hard margin has no solution. The soft margin allows some violations.
  • Cost: J(w, b) = ½‖w‖² + C Σ ζᵢ with ζᵢ = max(0, 1 − yᵢ(wᵀxᵢ + b)) (the hinge loss).
  • ζ = 0 for a point on the correct side of its margin line; 0 < ζ ≤ 1 for a correct point inside the margin; ζ > 1 for a misclassified point.
  • Large C: violations are penalised strongly, giving a smaller margin and fewer training errors, with a risk of overfitting.
  • Small C: more violations are allowed, giving a wider margin and more training errors, with a risk of underfitting.
Exam line

Hyperplane w·x + b = 0, margin lines w·x + b = ±1, constraint yᵢ(w·xᵢ + b) ≥ 1, margin d = 2/‖w‖, so maximize 2/‖w‖, which is minimize ½‖w‖². Soft margin: J = ½‖w‖² + C Σ ζᵢ with ζᵢ = max(0, 1 − yᵢ(wᵀxᵢ + b)). Large C: smaller margin, overfitting risk. Small C: wider margin, underfitting risk.

Question 3 · Open question · Lecture 6.1, K-Means clustering

K-Means clustering

  1. (a)List the steps of the K-Means algorithm. Write its objective function J and the centroid formula.
  2. (b)Name three challenges of K-Means and the solution the lecture gives for each.
  3. (c)Explain how K-Means++ chooses the initial centroids and why it is used.

(a) Steps

  • 1. Initialization: randomly select K points from the dataset as the initial centroids.
  • 2. Assignment: compute the distance from each point to each centroid, and assign the point to the closest centroid.
  • 3. Update centroids: each centroid becomes the mean of the points assigned to it.
  • 4. Repeat 2 and 3 until convergence: the centroids stop changing significantly, or a set number of iterations is reached.
  • 5. Final result: the final centroids and the cluster of every point.

J = Σk=1..K Σxᵢ ∈ Cₖ ‖xᵢ − μₖ‖²     μₖ = (1/|Cₖ|) Σxᵢ ∈ Cₖ xᵢ

(b) Challenges and solutions

ChallengeSolution
Choosing K: too small under-clusters, too large over-clustersElbow method: plot inertia (J) against K and pick the K where the drop levels off
Clusters of different sizes or densities: dense groups are merged, loose groups are splitUse a higher number of clusters (e.g. k = 10 instead of 3)
Outliers drag the centroids (the mean is sensitive to extreme values)Find and handle outliers first: remove, transform, or use a robust variant
Random initialization gives different clusters on every runK-Means++ initialization

(c) K-Means++

  • 1. Pick the first centroid uniformly at random from the data points.
  • 2. For each point x compute D(x), the distance to the nearest centroid already chosen.
  • 3. Pick the next centroid from the data points with probability proportional to D(x)².
  • 4. Repeat 2-3 until K centroids are chosen, then run normal K-Means.
  • Far-away points are likely to become centroids, so the starting centroids are spread out. This gives better clusters, and K-Means then often converges faster, even though the initialization itself costs more.

P(x is the next centroid) = D(x)² / Σ D(x′)²

Exam line

Initialize, assign each point to the nearest centroid, update each centroid to the mean of its points, repeat until the centroids stop changing. J = Σₖ Σxᵢ ∈ Cₖ ‖xᵢ − μₖ‖². Fixes: elbow method for K, more clusters for unequal sizes or densities, handle outliers first, K-Means++ for the start (next centroid with probability ∝ D(x)²).

Question 4 · Problem · Lecture 2.2, Logistic regression

Logistic regression: one gradient descent step

Training data (x0 = 1 is already added), learning rate α = 0.5, initial θ = [0, 0, 0]ᵀ:

  1. (a)Compute hθ(x) for every example and the cost J(θ) at the initial θ.
  2. (b)Perform one gradient descent update, θ := θ − α(1/m)Xᵀ(h − y). Give the new θ.
  3. (c)Compute the new predictions and the new cost. Did the cost go down?
  4. (d)Write the decision boundary for the new θ, and classify x = (4, 4) and x = (0, 0).

(a) Worked solution

  • With θ = 0: Z = Xθ = [0, 0, 0, 0, 0] and h = g(0) = 0.5 for every row.
  • Every row costs −log(0.5) = 0.693, whatever its label, so J = 0.693 (= ln 2).
J = −(1/m) Σ [ y log h + (1 − y) log(1 − h) ]
  = −(1/5) × 5 × log 0.5 = 0.693

(b) Worked solution

  • h − y = [0.5, 0.5, 0.5, −0.5, −0.5].
  • Each row of Xᵀ (one feature over all five examples) is multiplied with h − y and summed, then divided by m = 5.
Xᵀ(h − y) = [0.5, −1.5, −0.5]     ÷ 5 → [0.1, −0.3, −0.1]
θ = [0, 0, 0] − 0.5 × [0.1, −0.3, −0.1] = [−0.05, 0.15, 0.05]

Result: θ = [−0.05, 0.15, 0.05]

(c) Worked solution

  • z = −0.05 + 0.15x₁ + 0.05x₂ for each row:
  • J = (0.7710 + 0.8544 + 0.7981 + 0.4555 + 0.4201)/5 = 0.6598, down from 0.693. The step went in the right direction.
  • Rows 1-3 still have h > 0.5, so they are still predicted 1 (wrong). More iterations are needed, as in the lecture example.

(d) Worked solution

  • Boundary: θᵀx = 0, i.e. −0.05 + 0.15x₁ + 0.05x₂ = 0, or 3x₁ + x₂ = 1.
  • x = (4, 4): z = −0.05 + 0.6 + 0.2 = 0.75, h = 0.679 ≥ 0.5, so y = 1.
  • x = (0, 0): z = −0.05, h = 0.4875 < 0.5, so y = 0.

Result: boundary 3x₁ + x₂ = 1; (4, 4) → y = 1, (0, 0) → y = 0.

Exam line
