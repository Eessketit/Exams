Question 1 · Open question · Lecture 3.1, Evaluating learning algorithms

Classification metrics

  1. (a)Draw the confusion matrix of a binary classifier and define TP, FP, FN and TN.
  2. (b)Give the formulas of accuracy, precision, recall and F1-score, and the question that precision and recall each answer.
  3. (c)Which metric should a spam filter prioritise, and which one a cancer screening test? Why can accuracy be misleading?

(a) Draw (slide 14 layout: columns = actual, rows = predicted)

  • TP: predicted positive, actually positive. TN: predicted negative, actually negative.
  • FP: predicted positive, actually negative (a false alarm). FN: predicted negative, actually positive (a miss).
  • Read the name as: second word = what the model predicted, first word = whether that prediction was right. On the exam, always check which axis is "Actual" before reading off FP and FN.

(b) Formulas

  • Accuracy = (TP + TN)/(TP + TN + FP + FN) · 100%. The share of all predictions that are correct.
  • Precision = TP/(TP + FP). "Of all the alarms the model raised, how many were real?" It looks only at the positive predictions.
  • Recall (sensitivity) = TP/(TP + FN). "Of all the real positives out there, how many did the model actually catch?" It looks only at the actual positives.
  • F1 = 2 · Precision · Recall / (Precision + Recall). The harmonic mean, one number that balances both.
TP = 30, FP = 10, FN = 20, TN = 40   (100 cases)
accuracy  = (30 + 40) / 100              = 70%
precision = 30 / (30 + 10) = 30 / 40     = 0.75
recall    = 30 / (30 + 20) = 30 / 50     = 0.60
F1        = 2 · 0.75 · 0.60 / 1.35       = 0.667

(c) What to write

  • Spam filter: precision. An FP puts a real email (a job offer) into spam, and users stop trusting the filter.
  • Cancer screening: recall. An FN (a missed cancer) can be fatal, while a false alarm only costs an extra test. Airport weapon detection is the same case.
  • Accuracy misleads on imbalanced data. With 95 negatives and 5 positives, a model that always says "negative" has 95% accuracy and recall 0. It never finds a positive. Use precision, recall and F1 instead.
Exam line

Slide 14 layout: columns = actual, rows = predicted, TP top left, FP top right. Precision = TP/(TP + FP), "of all the alarms the model raised, how many were real?". Recall = TP/(TP + FN), "of all the real positives, how many did the model catch?". F1 = 2 · P · R/(P + R). Spam filter: precision. Cancer screening: recall. Accuracy misleads when the classes are imbalanced.

Question 2 · Open question · Lecture 4.1, Random forest

Random forest

  1. (a)What is a random forest?
  2. (b)Describe the steps used to build a random forest and to make a prediction with it.
  3. (c)Why does a random forest overfit less than a single decision tree? List its key features.

(a) What to write

  • A random forest is an ensemble of many decision trees. Each tree sees a random part of the data, and the predictions are combined: majority voting for classification, averaging for regression.

(b) Steps

  • 1. Bootstrap. Build many trees, each on a bootstrapped dataset: rows sampled from the original with replacement, same size as the original. Some rows appear twice, others are left out.
  • 2. Random features. At each split, look at only a few random features, not all of them (e.g. one tree on Outlook, Humidity, Wind; another on Outlook, Temp, Humidity).
  • 3. Predict. Each tree makes its own prediction for the new example.
  • 4. Combine. Majority vote (classification) or average (regression). In the slide 46 example all three trees say No, so the forest says No.

(c) What to write

  • A single deep tree learns the noise in its training data (overfitting). The trees of a forest are built on different rows and different features, so they make different errors. The vote averages those errors out. The slide's assumption: "diverse predictions improve accuracy".
  • Key features (slide 48): handles missing data, gives feature importance, works with big and complex data, and does both classification and regression.
  • Assumptions (slide 50): trees decide independently, they are built on random rows and features, and there must be enough data for the trees to differ.
Exam line

A random forest is an ensemble of many decision trees. Each tree is built on a bootstrapped dataset (rows sampled with replacement) and looks at only a few random features at each split. The trees vote (classification) or are averaged (regression). Different rows and features make different errors, and the vote cancels them, so the forest overfits less than one tree.

Question 3 · Open question · Lecture 6.2, Principal component analysis

Principal component analysis

  1. (a)What is PCA, and why do we use it?
  2. (b)What are principal components? Explain how the first and second principal components are constructed.
  3. (c)List the five steps of PCA, with their formulas.

(a) What to write

  • PCA is a dimensionality reduction method. It transforms a large set of variables into a smaller one that still contains most of the information.
  • Why: smaller data sets are easier to explore and visualize, and faster for ML algorithms. We trade a little accuracy for simplicity. The idea is to reduce the number of variables while preserving as much information as possible.

(b) What to write

  • Principal components are new variables built as linear combinations of the initial variables. They are uncorrelated, and most of the information is squeezed into the first ones. p variables give p components.
  • Geometrically they are the directions of maximal variance. More variance along a line means more spread, which means more information.
  • PC1: the line through the centred data on which the projected points are the most spread out, i.e. that maximizes the variance of the projections.
  • PC2: computed the same way, with the condition that it is uncorrelated with (perpendicular to) PC1 and carries the next highest variance. This continues until all p components are found.
  • The components have no real meaning (they are less interpretable), because each one mixes all the original variables.

(c) Steps

  • 1. Mean of each variable: X̄ = Σxᵢ/m, then centre the data (subtract the mean).
  • 2. Covariance matrix S = [[Cov(X₁,X₁), Cov(X₁,X₂)], [Cov(X₂,X₁), Cov(X₂,X₂)]], with Cov(x, y) = (1/(n − 1)) Σ(xᵢ − x̄)(yᵢ − ȳ).
  • 3. Eigenvalues: solve det(S − λI) = 0.
  • 4. Eigenvectors: solve (S − λI)U = 0 and normalize. The eigenvector of the largest eigenvalue is u₁.
  • 5. First principal component: transformed data = X_centered · u₁.
Exam line

PCA reduces the number of variables while preserving as much information as possible. Principal components are uncorrelated linear combinations of the variables, the directions of maximal variance. PC1 maximizes the variance of the projections, PC2 does the same perpendicular to PC1. Steps: mean, covariance (n − 1), det(S − λI) = 0, (S − λI)U = 0, X_centered · u₁.

Question 4 · Problem · Lecture 3.2, Naive Bayes

Naive Bayes: the shopping dataset

The lecture's shopping dataset has 15 records, 10 Buy = Yes and 5 Buy = No. Frequency table:

  1. (a)Build the likelihood table: P(value | Yes), P(value | No) and P(value), plus the priors.
  2. (b)A customer comes on a Weekend, with Discount = Yes and Free Delivery = No. Using the lecture's method, compute P(Buy | X) and P(No Buy | X), normalize them, and predict.
  3. (c)Using Bayes theorem with one feature only, compute P(No Buy | Weekend).
  4. (d)What is the zero-frequency problem of Naive Bayes, and how is it fixed?

(a) Likelihood table

  • Divide each count by its class total (10 for Yes, 5 for No). P(value) = row total / 15.

(b) Worked solution

X = (Weekend, Discount = Yes, Free Delivery = No)
denominator = (4/15)(10/15)(4/15)            = 0.04741
Buy:     (2/10)(8/10)(1/10)(10/15) = 0.01067  ÷ 0.04741 = 0.225
No Buy:  (2/5)(2/5)(3/5)(5/15)     = 0.03200  ÷ 0.04741 = 0.675
sum = 0.225 + 0.675 = 0.9, not 1  →  normalize
Buy    = 0.225 / 0.9 = 25%
No Buy = 0.675 / 0.9 = 75%
  • Prediction: the customer will not buy. The single strongest factor is Free Delivery = No: P(FD = No | Yes) is only 1/10.

Result: P(Buy | X) = 25%, P(No Buy | X) = 75%, so No Buy.

(c) Worked solution

P(No Buy | Weekend) = P(Weekend | No Buy) · P(No Buy) / P(Weekend)
                    = (2/5)(5/15) / (4/15)
                    = 0.1333 / 0.2667 = 0.5

Result: P(No Buy | Weekend) = 0.5. On a weekend, buying and not buying are equally likely (2 of the 4 weekend visits were buys).

(d) What to write

  • Zero-frequency problem: if a feature value never appears with a class in the training data, its likelihood is 0, and the whole product for that class becomes 0, whatever the other features say.
  • Fix: Laplace smoothing (textbook context for the formula): add α = 1 to every count, P(v | c) = (count + 1)/(Nc + K), where K = number of values of the feature. Applied to (b) it gives Buy 38.6%, No Buy 61.4%. The decision (No Buy) is the same.
Exam line

Naive Bayes multiplies P(value | class) over the features and the prior, divides by the product of the P(value), and normalizes. For (Weekend, Discount Yes, Free Delivery No): Buy 25%, No Buy 75%. A zero count makes the whole product 0, and Laplace smoothing (+1 on every count) fixes it.

Question 5 · Problem · Lecture 6.2, Principal component analysis

PCA by hand

Find the first principal component of the dataset below.

  1. (a)Compute the mean of each variable and the centred data.
  2. (b)Compute the covariance matrix S (divide by n − 1).
  3. (c)Compute the eigenvalues of S and the unit eigenvector of the largest eigenvalue.
  4. (d)Project the centred data on it to get PC1. What share of the total variance does PC1 keep?

(a) Worked solution

X̄₁ = (1 + 4 + 4 + 5) / 4 = 14 / 4 = 3.5
X̄₂ = (2 + 2 + 5 + 5) / 4 = 14 / 4 = 3.5
centred: (−2.5, −1.5), (0.5, −1.5), (0.5, 1.5), (1.5, 1.5)

(b) Worked solution

Cov(X₁, X₁) = (6.25 + 0.25 + 0.25 + 2.25) / 3 = 9 / 3 = 3
Cov(X₂, X₂) = (2.25 + 2.25 + 2.25 + 2.25) / 3 = 9 / 3 = 3
Cov(X₁, X₂) = (3.75 − 0.75 + 0.75 + 2.25) / 3 = 6 / 3 = 2

S = [ 3  2 ]
    [ 2  3 ]

(c) Worked solution

det(S − λI) = (3 − λ)² − 2 · 2 = 0
(3 − λ)² = 4  →  3 − λ = ±2  →  λ₁ = 5,  λ₂ = 1
λ₁ = 5:  (3 − 5)u₁ + 2u₂ = 0  →  u₂ = u₁
normalize: u₁ = (1, 1)/√2 = (0.7071, 0.7071)
check: S·(1, 1) = (3 + 2, 2 + 3) = 5·(1, 1)
λ₂ = 1:  eigenvector (0.7071, −0.7071), perpendicular to u₁

Result: λ₁ = 5, λ₂ = 1, u₁ = (0.7071, 0.7071).

(d) Worked solution

PC1 = centred row · u₁ = (x̃₁ + x̃₂)/√2

  • Check: the variance of the PC1 values is (8 + 0.5 + 2 + 4.5)/3 = 5 = λ₁.
  • PC1 keeps λ₁/(λ₁ + λ₂) = 5/6 = 83.3% of the total variance, so the 2D data can be reduced to 1D with little loss.

Result: PC1 = −2.828, −0.707, 1.414, 2.121; it keeps 83.3% of the variance.

Exam line

Mean, centre, S with n − 1, det(S − λI) = 0, (S − λI)U = 0 and normalize, then PC1 = X_centered · u₁. Here S = [[3, 2], [2, 3]], λ = 5 and 1, u₁ = (0.7071, 0.7071), PC1 keeps 5/6 = 83.3%.

Question 6 · Problem · Lecture 4.1, Decision tree

Decision tree with ID3

Should the bank approve the loan?

  1. (a)Compute the entropy of the dataset.
  2. (b)Compute the information gain of Income, Credit and Employed, and choose the root.
  3. (c)Build the complete tree. Show the information gains used at the second level.
  4. (d)Predict Approve for {Low, Good, No} and for {Medium, Bad, Yes}.

(a) Worked solution

8 Yes, 4 No
E(S) = −(8/12) log₂(8/12) − (4/12) log₂(4/12)
     = 0.390 + 0.528 = 0.918

Result: E(S) = 0.918.

(b) Root

IG(S, a) = E(S) − Σv |Sv|/|S| · E(Sv)

  • Income wins and becomes the root. Income = High is pure (4/0), so it is a Yes leaf.

(c) Second level

  • Income = Medium (rows 4-7, 2 Yes / 2 No, E = 1): Credit gives Good 2/0 and Bad 0/2, IG = 1.0. Employed gives Yes 1/1 and No 1/1, IG = 0. Split on Credit.
  • Income = Low (rows 8-11, 2 Yes / 2 No, E = 1): Employed gives No 0/2 and Yes 2/0, IG = 1.0. Credit gives Good 1/1 and Bad 1/1, IG = 0. Split on Employed.
  • Each branch asks a different second question. ID3 picks the attribute separately in every subset.
Income [Yes=8, No=4]
|- High   -> Yes [4/0]
|- Medium -> Credit [Yes=2, No=2]
|              |- Good -> Yes [2/0]
|              |- Bad  -> No  [0/2]
|- Low    -> Employed [Yes=2, No=2]
               |- Yes -> Yes [2/0]
               |- No  -> No  [0/2]

(d) Worked solution

  • {Low, Good, No}: Income = Low, then Employed = No, so No.
  • {Medium, Bad, Yes}: Income = Medium, then Credit = Bad, so No.

Result: {Low, Good, No} → No; {Medium, Bad, Yes} → No.

Exam line

E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋, 0 for a pure node and 1 for 50/50. IG(S, a) = E(S) − Σ |Sv|/|S| · E(Sv), and the highest IG becomes the node. Here Income (IG 0.252) is the root, Medium splits on Credit and Low on Employed (IG 1.0 each), and a pure node becomes a leaf.
