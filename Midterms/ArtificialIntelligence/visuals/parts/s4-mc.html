Question 1 · Lecture 2.1, Loss and gradient descent

Linear regression with the loss J(θ) = (1/2m) Σ(hθ(x) − y)² is trained on x = [1, 2, 3], y = [2, 4, 6]. What is J at the initial θ = [0, 0]?

  1. a 9.333 Correct. 56/(2 × 3) = 56/6 = 9.333.
  2. b 18.667 No. 56/3 is the MSE with 1/m. This loss has the extra ½.
  3. c 56 No. 56 is the sum of squared errors before the division by 2m.
  4. d 4.667 No. 56/12 divides by 4m, twice too much.

Answer: a. With θ = [0, 0] the hypothesis hθ(x) = θ₀ + θ₁x is 0 for every x. The errors are −2, −4 and −6, and their squares add up to 4 + 16 + 36 = 56. With m = 3 examples, J = 56/(2 × 3) = 9.333.

18.667 = 56/3 is the mean squared error with 1/m. The loss in this lecture has the extra ½, so the sum is divided by 2m = 6.

Exam line

J(θ) = (1/2m) Σ (hθ(x⁽ⁱ⁾) − y⁽ⁱ⁾)², with the ½. At θ = 0 every prediction is 0, so J = Σy² / 2m = 56/6 = 9.333.

Question 2 · Lecture 2.2, Regularization

In regularized logistic regression, the penalty is (λ/2m) Σⱼ θⱼ². Which parameter is NOT regularized?

  1. a θ₁ No. θ₁ is the first term of the penalty sum, j = 1.
  2. b The parameter of the largest feature No. The penalty treats every θj with j ≥ 1 the same way, whatever its feature.
  3. c All parameters are regularized equally No. The sum starts at j = 1, so θ₀ is left out.
  4. d θ₀, the bias Correct. The penalty sum runs from j = 1 to n.

Answer: d. The penalty sum runs from j = 1 to n, so θ₀ keeps the plain update θ₀ := θ₀ − α(1/m)Σ(h − y)x₀. For j ≥ 1 the gradient gets the extra term (λ/m)θj, which pulls θj toward 0.

θ₀ only shifts the decision boundary. It does not make the model more complex, so there is no reason to shrink it.

Exam line

Regularization adds (λ/2m) Σj=1n θj² to the cost, so only θ₁ … θₙ are penalized. θ₀ keeps the plain update θ₀ := θ₀ − α(1/m)Σ(h − y)x₀, and every other θj gets the extra (λ/m)θj.

Question 3 · Lecture 3.1, Precision and recall

A classifier has TP = 30, FP = 10, FN = 20, TN = 40. What is its recall?

  1. a 0.75 No. 30/40 = 0.75 is precision, TP/(TP + FP).
  2. b 0.70 No. (30 + 40)/100 = 0.70 is accuracy.
  3. c 0.60 Correct. TP/(TP + FN) = 30/50 = 0.60.
  4. d 0.667 No. 0.667 is F1, the harmonic mean of 0.75 and 0.60.

Answer: c. Recall = TP/(TP + FN) = 30/(30 + 20) = 0.60. It answers the slide's question "Of all the real positives out there, how many did the model actually catch?" There are 30 + 20 = 50 actual positives, and the model caught 30 of them.

The other options are the other metrics of the same matrix. Precision = 30/40 = 0.75, accuracy = 70/100 = 0.70 and F1 = 0.667. Recall looks only at the actual positives.

Exam line

Recall (Sensitivity) = TP/(TP + FN), the share of actual positives caught. Precision = TP/(TP + FP), the share of alarms that were real. Here recall = 0.60, precision = 0.75, accuracy = 0.70, F1 = 0.667.

Question 4 · Lecture 3.2, Naive Bayes

In Naive Bayes, a feature value never appears together with one class in the training data, so the whole product for that class becomes 0. What fixes this zero-frequency problem?

  1. a Feature scaling No. Scaling changes distances. Naive Bayes multiplies counted probabilities, and a zero count stays zero.
  2. b Laplace smoothing Correct. Adding 1 to every count leaves no likelihood at exactly 0.
  3. c Removing the class No. That throws away a real class to hide one missing count.
  4. d Using a larger k No. k is the number of neighbours in KNN. Naive Bayes has no k.

Answer: b. Naive Bayes multiplies P(class) by one likelihood P(value | class) per feature. If a value never appeared with a class, its likelihood is 0/Nc = 0, and the product for that class is 0 whatever the other features say.

Laplace smoothing adds a small count (α = 1) to every value, so no likelihood is exactly 0: P(v | c) = (count + 1)/(Nc + K), where K is the number of values the feature can take. Scaling and k belong to distance-based methods such as KNN.

Exam line

Zero-frequency problem: an unseen value gets probability 0 and wipes out the whole product. Fix: Laplace smoothing, P(v | c) = (count + 1)/(Nc + K).

Question 5 · Lecture 4.1, Random forest

How does a random forest make each of its trees different?

  1. a Each tree is trained on a bootstrapped sample of the rows (with replacement) and considers only a random subset of the features; the trees then vote Correct. Random rows plus random features keep the trees different, and the majority vote combines them.
  2. b Each tree uses a different impurity measure No. All trees use the same split criterion. The randomness is in the rows and the features.
  3. c Each tree is trained on the same data with a different maximum depth No. Greedy splits on the same data give the same tree, and a depth limit only cuts it shorter.
  4. d Each tree is trained on the errors of the previous tree No. That is boosting, where trees are built one after another.

Answer: a. Each tree gets its own bootstrap sample, rows drawn at random with replacement, so some rows appear twice and others are left out. At the splits each tree looks at only a few random features. The final answer is the majority vote, or the average for regression.

Option d describes boosting, which is a different ensemble method and is not the random forest.

Exam line

Random forest = many decision trees, each on a bootstrapped sample (rows drawn with replacement) and a few random features at the splits. Majority voting for classification, averaging for regression.

Question 6 · Lecture 4.2, Soft margin

What happens when the hyperparameter C of a soft-margin SVM is made very large?

  1. a The margin gets wider and more training errors are allowed No. That describes a small C, which risks underfitting.
  2. b The SVM ignores the support vectors No. The boundary is still set by the support vectors, the points on or inside the margin.
  3. c The kernel becomes linear No. C does not change the kernel. The kernel is chosen separately.
  4. d Margin violations are penalised strongly: the margin gets smaller, there are fewer training errors, and the model may overfit Correct. Every violation costs C × ζᵢ, so the SVM narrows the margin to avoid them.

Answer: d. The soft-margin cost is J = ½‖w‖² + C Σζᵢ. The first term is small when the margin 2/‖w‖ is wide. The second term charges C for every unit of slack ζᵢ, the amount by which a point violates its margin.

A very large C makes every violation expensive, so the SVM narrows the margin until it classifies the training points correctly. It then follows single odd points, with a risk of overfitting. A small C does the opposite (option a), with a risk of underfitting.

Exam line

J = ½‖w‖² + C Σζᵢ. Large C: violations penalised strongly, smaller margin, fewer misclassifications, risk of overfitting. Small C: more violations allowed, wider margin, risk of underfitting.

Question 7 · Lecture 5.2, Outliers

For the data 2, 4, 4, 5, 6, 7, 8, 8, 30 we have Q1 = 4 and Q3 = 8. Which value is an outlier by the IQR rule?

  1. a 2 No. 2 is above the lower bound −2.
  2. b 30 Correct. 30 is above the upper bound 14.
  3. c 8 No. 8 is Q3 itself, inside [−2, 14].
  4. d None of them No. 30 lies outside the bounds.

Answer: b. IQR = Q3 − Q1 = 8 − 4 = 4. The bounds are Q1 − 1.5·IQR = 4 − 6 = −2 and Q3 + 1.5·IQR = 8 + 6 = 14. Only 30 lies outside [−2, 14].

The bounds come from the quartiles, so the extreme value does not drag them toward itself. The slide calls the rule robust and distribution-free.

Exam line

IQR = Q3 − Q1. A value is an outlier if it is below Q1 − 1.5·IQR or above Q3 + 1.5·IQR. Here IQR = 4, the bounds are −2 and 14, and 30 is the outlier.

Question 8 · Lecture 5.2, Class imbalance

A fraud dataset is heavily imbalanced, and SMOTE is used to create synthetic fraud examples. Where should SMOTE be applied?

  1. a On the whole dataset before splitting No. Synthetic points built from test rows leak into training, and synthetic points land in the test set.
  2. b On the test set only No. The model still trains on 0.2% fraud, and the test set loses the real class balance.
  3. c On the training data only Correct. "SMOTE only on TRAINING data. Never resample the test set."
  4. d On both the training and the test set No. Slide 36 lists applying SMOTE to the test set as a common mistake.

Answer: c. "SMOTE only on TRAINING data. Never resample the test set." The test set must keep the real class balance, or the scores are inflated by synthetic points. That is data leakage.

SMOTE creates a new fraud point by interpolating between a fraud point and one of its k nearest fraud neighbours. If test rows take part, their information ends up in the training data.

Exam line

SMOTE: pick a minority point, find its k nearest minority neighbours, interpolate a new point between them, add it to the training set. SMOTE only on TRAINING data. Never resample the test set.

Question 9 · Lecture 6.1, K-Means

What does the K-Means algorithm minimize?

  1. a The sum of squared distances between each point and the centroid of its cluster Correct. J = Σₖ Σ ‖xᵢ − μₖ‖² over the points of each cluster.
  2. b The number of clusters K No. K is chosen beforehand. It is an input, and J keeps falling as K grows.
  3. c The distance between the centroids of different clusters No. J measures each point against its own centroid only.
  4. d The number of points in the largest cluster No. Cluster sizes do not appear in J.

Answer: a. J = Σₖ Σxᵢ ∈ Cₖ ‖xᵢ − μₖ‖². Points inside a cluster should be similar, so K-Means makes the distance from each point to its own centroid small.

Both steps of the algorithm lower J. The assignment step moves each point to its nearest centroid, and the update step moves each centroid to the mean of its points. K is chosen beforehand and is not minimized.

Exam line

K-Means minimizes J = Σₖ Σxᵢ ∈ Cₖ ‖xᵢ − μₖ‖², the sum of squared distances between the objects and their cluster centroid. K is predefined.

Question 10 · Lecture 6.2, Principal components

Which statement about principal components is correct?

  1. a They are a subset of the original variables No. Choosing a subset of the original variables is feature selection.
  2. b Each one keeps the same amount of information No. PC1 holds the most information, PC2 the next most, and so on.
  3. c They are always easy to interpret, like the original variables No. Each PC mixes all the variables, so it is less interpretable.
  4. d They are new uncorrelated variables built as linear combinations of the original variables Correct. This is the slide-6 definition.

Answer: d. Principal components are new variables built as linear combinations (mixtures) of the initial variables. They are constructed to be uncorrelated, and most of the information is squeezed into the first ones.

Because each one mixes the variables, they are less interpretable and have no real meaning of their own. Choosing a subset of the original variables (a) is feature selection.

Exam line

Principal components are new variables constructed as linear combinations of the initial variables. They are uncorrelated, most information is in the first components, and they are less interpretable.

Source: L6.2 p.6 PCs are uncorrelated linear combinations · L6.2 p.7 less interpretable, no real meaning · Notes: L6.2 › Principal components
