Question 1 · Lecture 2.1, Normal equation

A multivariate linear regression dataset has m = 5 examples and n = 3 features. After the dummy feature x0 = 1 is added, what is the shape of the matrix X used in the normal equation θ = (XᵀX)⁻¹Xᵀy?

  1. a 5 × 3 No. That is the dataset before x₀ is added. It forgets the column of 1s.
  2. b 3 × 5 No. Rows and columns are swapped, and the x₀ column is still missing.
  3. c 5 × 4 Correct. m rows by n + 1 columns: 5 × (3 + 1) = 5 × 4.
  4. d 4 × 4 No. 4 × 4 is the shape of XᵀX, the square matrix the normal equation inverts.

Answer: c. X has one row per example and one column per parameter. There are m = 5 examples, and the parameters are θ₀ for the dummy feature x₀ = 1 plus θ₁, θ₂, θ₃ for the n = 3 features. So X is m × (n + 1) = 5 × 4.

XᵀX is (4 × 5)(5 × 4) = 4 × 4, which is option d. Option a is the feature table before the column of 1s goes in.

Exam line

Add the dummy feature x₀ = 1, then X is m × (n + 1), θ is (n + 1) × 1 and h = Xθ is m × 1. XᵀX is (n + 1) × (n + 1).

Question 2 · Lecture 2.2, Sigmoid hypothesis

Logistic regression uses hθ(x) = g(z) with z = θᵀx and g(z) = 1 / (1 + e⁻ᶻ). When does it predict y = 1?

  1. a When z ≥ 0 Correct. g(0) = 0.5 and g increases, so h ≥ 0.5 exactly when z ≥ 0.
  2. b When z ≥ 0.5 No. The 0.5 threshold is on h, not on z. g(0.5) = 0.62.
  3. c When hθ(x) ≥ 0 No. h is always between 0 and 1, so this rule says y = 1 for every input.
  4. d When z ≤ 0 No. That is the y = 0 side, where h ≤ 0.5.

Answer: a. Logistic regression predicts y = 1 when hθ(x) ≥ 0.5. The sigmoid passes through g(0) = 0.5 and only goes up, so g(z) ≥ 0.5 if z ≥ 0 and g(z) < 0.5 if z < 0 (slide 12).

So "h ≥ 0.5" and "θᵀx ≥ 0" are the same rule. Option b puts the 0.5 on the wrong side of g.

Exam line

g(z) ≥ 0.5 if z ≥ 0, so predict y = 1 when θᵀx ≥ 0. The decision boundary is θᵀx = 0, where h = 0.5.

Question 3 · Lecture 3.1, Precision and recall

A spam filter must avoid moving real emails (for example a job offer) into the spam folder. Which metric should it prioritise?

  1. a Recall No. Recall punishes False Negatives, spam that reaches the inbox. It ignores FP.
  2. b Precision Correct. Precision = TP / (TP + FP), and a real email in the spam folder is a FP.
  3. c Accuracy No. Accuracy counts a FP and a FN the same, so it cannot single out the costly error.
  4. d MAE No. MAE is a regression metric. Spam filtering is classification.

Answer: b. Spam is the positive class. Moving a real email into the spam folder is a False Positive. Precision = TP / (TP + FP) answers "of all the alarms the model raised, how many were real?", so every FP lowers it.

The slide's own example for precision is spam detection (slide 22). Recall is for problems where a False Negative is the costly error, such as cancer screening.

Exam line

Precision = TP / (TP + FP): prioritise it when a False Positive is expensive, as in spam detection. Recall = TP / (TP + FN): prioritise it when a False Negative is dangerous, as in cancer screening.

Question 4 · Lecture 3.2, Naive Bayes

Why is the Naive Bayes classifier called "naive"?

  1. a It gives every class the same prior probability No. Priors come from the class counts: 10/15 for Buy and 5/15 for No Buy.
  2. b It uses only one feature to classify No. It multiplies one likelihood per feature, so it uses all of them.
  3. c It works only on continuous data No. Slide 27 says it handles continuous and discrete data. The shopping example is all categories.
  4. d It assumes the features are independent of each other given the class Correct. That lets it write P(x₁, ..., xₙ | class) as a product of one-feature terms.

Answer: d. Naive Bayes assumes the features are conditionally independent given the class. Then P(x₁, ..., xₙ | class) = P(x₁ | class) · ... · P(xₙ | class), and each factor is one easy count.

Slide 28 lists this assumption as the main disadvantage, because it is rarely true for real data. The slide's own shopping data already breaks it, as Figure 1 shows.

Question 5 · Lecture 3.2, Choosing k

In KNN classification, what does the model predict if k is set equal to N, the number of training points?

  1. a The majority class of the whole training set, for every query Correct. Every point votes for every query, so the vote never changes.
  2. b The label of the single nearest point No. That is k = 1, the other end of the range.
  3. c A random class No. KNN is deterministic. With k = N the vote is always the same.
  4. d The class whose mean is nearest to the query No. That is a nearest-centroid rule. KNN never computes class means.

Answer: a. KNN takes the majority vote of the k nearest training points. With k = N every training point is a neighbour, whatever the query. The vote is then the same for every query: the most frequent class in the dataset.

Slide 46: k ranges from 1, only the closest point, to N, which always predicts the dataset's majority class. Small k overfits, large k smooths, and k = N ignores the query completely.

Exam line

k ranges from 1 (only the closest point) to N (always predicts the dataset's majority class). Low k overfits, high k smooths.

Question 6 · Lecture 4.1, Entropy

A decision-tree node holds 7 "Yes" and 7 "No" examples. Its entropy (log base 2) is:

  1. a 0 No. 0 is a pure node, all Yes or all No.
  2. b 0.5 No. 0.5 is each class's probability, not the entropy.
  3. c 1 Correct. −0.5 log₂ 0.5 − 0.5 log₂ 0.5 = 0.5 + 0.5 = 1.
  4. d 0.940 No. 0.940 is the PlayTennis root, 9 Yes and 5 No.

Answer: c. Both classes have probability 7/14 = 0.5. E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋ = −0.5 × (−1) − 0.5 × (−1) = 0.5 + 0.5 = 1.

1 is the maximum for two classes: a 50/50 node is the least pure. "Higher entropy means lower purity and higher impurity."

Exam line

E(S) = −p₊ log₂ p₊ − p₋ log₂ p₋. A pure node has E = 0 and becomes a leaf; a 50/50 node has E = 1, the maximum for two classes.

Source: L4.1 p.22, p.24-28 · Notes: L4.1 › Entropy

Question 7 · Lecture 4.2, Support vectors

Which training points determine the separating hyperplane of an SVM?

  1. a All training points, each with equal weight No. That describes logistic regression, which is defined over all points (slide 11).
  2. b The mean point of each class No. A line from the class means moves whenever any point moves. The SVM line does not.
  3. c The points farthest from the hyperplane No. It is the opposite. The far points can move freely without changing anything.
  4. d Only the support vectors, the points closest to the hyperplane Correct. "The SVM is defined only by the support vectors."

Answer: d. Support vectors are the points closest to the hyperplane, the ones that sit on the margin lines. The maximum-margin hyperplane is fixed by them alone.

The other points can move, as long as they do not cross the margin, and the hyperplane does not change. Logistic regression, by contrast, is defined over all points (slide 11).

Exam line

Support vectors are the points closest to the hyperplane. The SVM is defined only by the support vectors; logistic regression is defined over all points.

Question 8 · Lecture 5.2, Missing values

In a salary survey, high earners often leave the income question blank. This type of missing data is:

  1. a MCAR (Missing Completely At Random) No. MCAR is unrelated to any variable, like a sensor that briefly went offline.
  2. b MNAR (Missing Not At Random) Correct. The value is missing because of the value itself: a high income.
  3. c MAR (Missing At Random) No. MAR depends on another observed variable, like older respondents skipping income questions.
  4. d A duplicate record No. A duplicate is an extra copy of a row, not a blank value.

Answer: b. Whether the income is missing depends on the income itself: the higher it is, the more likely the blank. That is MNAR, Missing Not At Random, the hardest case. High earners hiding their income is the slide's own MNAR example.

MNAR is hard because nothing in the observed data reveals it. The answers that remain look normal, but their average is too low.

Exam line

MCAR: not related to any variable (a sensor briefly went offline). MAR: related to other observed variables (older respondents skip income questions). MNAR: depends on the missing value itself (high earners hide their income), the hardest case.

Source: L5.2 p.10 · Notes: L5.2 › Missing values

Question 9 · Lecture 6.1, K-Means steps

In the K-Means algorithm, what happens in the "update centroids" step?

  1. a Each point moves to the nearest centroid No. Points never move. Joining the nearest centroid's cluster is the assignment step.
  2. b A new centroid is picked at random from the data No. Random picks happen only once, at initialization.
  3. c Each centroid becomes the mean of all points assigned to its cluster Correct. μₖ = (1/|Cₖ|) Σ xᵢ over the points in cluster k.
  4. d The centroid with the most points is split in two No. K is fixed in advance. Splitting clusters belongs to other methods.

Answer: c. Step 3 of K-Means recomputes every centroid as the mean of the points assigned to it, μₖ = (1/|Cₖ|) Σ xᵢ over xᵢ ∈ Cₖ. The points stay where they are. Only the centroids move.

Step 2, the assignment, gives each point to its nearest centroid. Steps 2 and 3 repeat until the centroids stop changing.

Exam line

Initialize K centroids from the data, assign each point to the closest centroid, update each centroid to the mean of its points, μₖ = (1/|Cₖ|) Σ xᵢ, and repeat until the centroids no longer change.

Question 10 · Lecture 6.2, Principal components

The first principal component of a dataset is the direction that:

  1. a maximizes the variance of the data projected onto it Correct. PC1 is the line on which the projections are the most spread out.
  2. b minimizes the variance of the data projected onto it No. In 2D that is the last component, PC2, which keeps the least information.
  3. c is always parallel to the x1 axis No. PC1 can point in any direction. It follows the data, not the axes.
  4. d passes through the point farthest from the origin No. One point does not set the direction. All points count through their variance.

Answer: a. PC1 is "the line in which the projection of the points is the most spread out", the line that maximizes the variance. Larger variance means more information along that line.

PC2 is perpendicular to PC1 and carries the next highest variance. On the slide 17 data, PC1 keeps 30.38 of the total variance 37, or 82.1%.

Exam line

Principal components are the directions of maximal variance. PC1 is the line on which the projections of the points are most spread out; PC2 is perpendicular to PC1 and carries the next highest variance.
