Question 1 · Lecture 2.1, Gradient descent vs normal equation

Which statement about gradient descent and the normal equation is TRUE?

  1. a The normal equation needs a learning rate α No. Slide 42: the normal equation has "no need to choose α". Gradient descent is the method that needs α.
  2. b The normal equation needs many iterations to reach the optimum No. The normal equation has "no need for iterations". It computes θ in one step.
  3. c The normal equation becomes very slow when the number of features is very large, because (XᵀX)⁻¹ must be computed Correct. Slide 42: (Xᵀ·X)⁻¹ needs to be calculated, so the method is "very slow if the number of features is very large".
  4. d Gradient descent does not need a learning rate No. Gradient descent has to "choose learning rate α". Too small is slow, too large diverges.

Answer: c. The normal equation θ = (XᵀX)⁻¹Xᵀy solves for θ directly, so it needs no α and no iterations. The price is the inverse of XᵀX, an (n+1) × (n+1) matrix for n features. Inverting it takes about n³ operations, which becomes very slow when n is very large.

Gradient descent needs α and a lot of iterations, but one iteration costs only about m × n operations. That is why it stays very good when the number of features is very large.

Exam line

Gradient descent: need to choose α, a lot of iterations, very good if the number of features is very large. Normal equation: no α, no iterations, but (Xᵀ·X)⁻¹ needs to be calculated, so it is very slow if the number of features is very large.

Question 2 · Lecture 2.2, Cost function: log loss

For one training example with y = 1, logistic regression outputs hθ(x) = 0.1. What is the cost of this example (natural log)?

  1. a 0.105 No. 0.105 = −ln 0.9, the cost when h = 0.9, a good prediction.
  2. b 2.303 Correct. For y = 1, Cost = −log(hθ(x)) = −ln 0.1 = 2.303.
  3. c 0.693 No. 0.693 = −ln 0.5, the cost at h = 0.5.
  4. d 0.9 No. 0.9 = 1 − h, the plain error y − h. Log loss takes the log of h.

Answer: b. For y = 1 the cost is −log(hθ(x)), so −ln 0.1 = 2.303. The model gave only 10% to the true class. That is a confident wrong answer, and the y = 1 cost curve rises steeply as h goes to 0.

In the compact form Cost = −y log(h) − (1 − y) log(1 − h), y = 1 removes the second term.

Exam line

Cost = −log(hθ(x)) if y = 1 and −log(1 − hθ(x)) if y = 0. For y = 1 and h = 0.1 the cost is −ln 0.1 = 2.303. Confident wrong answers are punished hard.

Question 3 · Lecture 3.1, R-squared

A regression model has SS_res = Σ(y − ŷ)² = 20 and SS_tot = Σ(y − ȳ)² = 80 on the test set. What is R²?

  1. a 0.25 No. 0.25 = SS_res/SS_tot, the share of variance the model leaves unexplained.
  2. b 4 No. 4 = SS_tot/SS_res. R² can never be above 1.
  3. c −3 No. −3 = 1 − 80/20 puts the fraction upside down.
  4. d 0.75 Correct. R² = 1 − SS_res/SS_tot = 1 − 20/80 = 0.75.

Answer: d. R² = 1 − SS_res/SS_tot = 1 − 20/80 = 0.75. SS_tot is the squared error of always predicting the mean ȳ. SS_res is the squared error left over by the model. The model removes 60 of the 80, so it explains 75% of the variance of the target.

R² = 1 is a perfect fit and R² = 0 is no better than always predicting the mean.

Exam line

R² = 1 − SS_res/SS_tot with SS_res = Σ(y − ŷ)² and SS_tot = Σ(y − ȳ)². Close to 1 = good fit. 1 − 20/80 = 0.75.

Question 4 · Lecture 3.2, Distance measures

The Minkowski distance with p = 1 between the points (1, 2) and (4, 6) is:

  1. a 7 Correct. p = 1 is the Manhattan distance: |1 − 4| + |2 − 6| = 3 + 4 = 7.
  2. b 5 No. 5 = √(9 + 16) is p = 2, the Euclidean distance.
  3. c 4.50 No. 4.50 = (27 + 64)^(1/3) is p = 3.
  4. d 25 No. 25 = 3² + 4² is the squared Euclidean distance, before the square root.

Answer: a. The Minkowski distance is (Σ|xᵢ − yᵢ|ᵖ)^(1/p). With p = 1 the power and the root drop out, and it becomes the Manhattan distance Σ|xᵢ − yᵢ| = |1 − 4| + |2 − 6| = 3 + 4 = 7.

p = 1 gives Manhattan and p = 2 gives Euclidean. Each larger p gives a shorter distance for the same two points.

Exam line

Minkowski (Σ|xᵢ − yᵢ|ᵖ)^(1/p): p = 1 gives Manhattan, p = 2 gives Euclidean. Between (1, 2) and (4, 6): Manhattan 3 + 4 = 7, Euclidean √25 = 5.

Question 5 · Lecture 3.2, Bayes theorem

Bayes theorem, as used by the Naive Bayes classifier, states that P(A | B) =

  1. a P(A) · P(B) No. That is P(A and B) only when A and B are independent. It ignores how B depends on A.
  2. b P(B | A) · P(B) / P(A) No. It swaps the prior P(A) and the evidence P(B).
  3. c P(B | A) · P(A) / P(B) Correct. Slide 7: P(A | B) = P(B | A) P(A) / P(B).
  4. d P(A | B) · P(B) No. That is P(A and B), and it uses P(A | B), the value we are looking for.

Answer: c. P(A | B) = P(B | A) P(A) / P(B). In the classifier A is the class (Buy / No Buy) and B is the features. P(A) is the prior, P(B | A) the likelihood read from the likelihood table, and P(B) the evidence.

The numerator P(B | A) P(A) is the share of all cases where A and B both happen. Dividing by P(B) keeps only the cases where B happened.

Exam line

P(A | B) = P(B | A) · P(A) / P(B). In Naive Bayes A is the class and B is the features. Posterior = likelihood × prior / evidence.

Question 6 · Lecture 4.1, Types of decision trees

Which decision tree algorithm chooses splits by Gini impurity and can be used for both classification and regression?

  1. a ID3 No. ID3 chooses splits by entropy (information gain).
  2. b CART Correct. CART uses the Gini impurity and does both classification and regression.
  3. c C4.5 No. C4.5 is an improved ID3 that handles missing data and continuous attributes.
  4. d KNN No. KNN is not a tree. It classifies a point by its k nearest neighbours.

Answer: b. CART (Classification And Regression Trees) chooses each split by the Gini impurity and builds both classification trees and regression trees. ID3 chooses splits by entropy (information gain), and C4.5 is an improved ID3 that handles missing data and continuous attributes. KNN is not a decision tree at all.

Exam line

ID3: entropy (information gain). C4.5: improved ID3, handles missing data and continuous attributes. CART: Gini impurity, classification and regression.

Question 7 · Lecture 4.2, Kernels

Using the polynomial kernel K(x, z) = (xᵀz + 1)^d with d = 2, x = (1, 2) and z = (3, −1), the kernel value is:

  1. a 1 No. 1 is the plain dot product xᵀz, the linear kernel.
  2. b 2 No. 2 = xᵀz + 1 forgets the square.
  3. c 9 No. 9 = 3² squares the wrong sum. The bracket holds xᵀz + 1 = 2.
  4. d 4 Correct. xᵀz = 1·3 + 2·(−1) = 1, so K = (1 + 1)² = 4.

Answer: d. First the dot product: xᵀz = 1·3 + 2·(−1) = 3 − 2 = 1. Then add 1 and raise to the degree d = 2: K = (1 + 1)² = 4.

The kernel value equals a dot product of the two points after a mapping into a higher-dimensional space, computed without building that mapping.

Exam line

Polynomial kernel (X1ᵀ·X2 + 1)^d, degree d set manually. For x = (1, 2), z = (3, −1), d = 2: xᵀz = 1, K = (1 + 1)² = 4.

Question 8 · Lecture 5.2, Feature scaling

A feature has min = 20 and max = 80 in the training set. Min-max scaling maps the value x = 35 to:

  1. a 0.25 Correct. (35 − 20)/(80 − 20) = 15/60 = 0.25.
  2. b 0.35 No. 0.35 = 35/100 divides by 100 and ignores the training range.
  3. c 0.44 No. 0.44 = 35/80 skips subtracting the min.
  4. d −0.25 No. −0.25 = (20 − 35)/60 subtracts in the wrong order.

Answer: a. x′ = (x − min)/(max − min) = (35 − 20)/(80 − 20) = 15/60 = 0.25. Subtracting the min moves the training minimum to 0. Dividing by the range max − min = 60 moves the maximum to 1.

So the training range [20, 80] becomes [0, 1], and 35 lies a quarter of the way along it.

Exam line

Min-Max scaling x′ = (x − min)/(max − min) maps the training range to [0, 1]. (35 − 20)/(80 − 20) = 0.25. Fit the scaler on the training data only.

Question 9 · Lecture 6.1, K-Means++ initialization

K-Means++ on the points A(1, 2), B(2, 1), C(5, 4), D(6, 5), E(9, 8). The first centroid is A. Squared distances to A are 0, 2, 20, 34, 100. What is the probability that E becomes the second centroid?

  1. a 0.2 No. 0.2 = 1/5 treats every point as equally likely, which is plain random initialization.
  2. b 1.0 No. K-Means++ does not always take the farthest point. It only makes it the most likely choice.
  3. c 0.641 Correct. P(E) = 100/(0 + 2 + 20 + 34 + 100) = 100/156 = 0.641.
  4. d 0.218 No. 0.218 = 34/156 is P(D).

Answer: c. K-Means++ chooses the next centroid with probability proportional to D(x)², the squared distance to the nearest centroid already chosen. The squared distances add up to 0 + 2 + 20 + 34 + 100 = 156, so P(E) = 100/156 = 0.641.

Far points are likely picks, but the pick is still random. Slide 23 then takes C₂ = E.

Exam line

K-Means++: first centroid at random, then choose the next centroid with probability proportional to D(x)², the squared distance to the nearest chosen centroid. P(E) = 100/156 = 0.641.

Question 10 · Lecture 6.2, PCA step by step

In the step-by-step PCA, which step comes right after computing the covariance matrix S?

  1. a Projecting the centred data on u₁ No. Projection is step 5, the last step.
  2. b Computing the eigenvalues from det(S − λI) = 0 Correct. Step 3 follows the covariance matrix (step 2).
  3. c Computing the mean of each variable No. The mean is step 1. S already needs it.
  4. d Computing the eigenvectors from (S − λI)U = 0 No. The eigenvectors need λ first, so this is step 4.

Answer: b. The order is: 1 mean of each variable, 2 covariance matrix S, 3 eigenvalues from det(S − λI) = 0, 4 eigenvectors from (S − λI)U = 0, 5 projection of the centred data on the first eigenvector u₁.

The eigenvector equation (S − λI)U = 0 contains λ, so the eigenvalues have to come first.

Exam line

PCA: 1 mean, 2 covariance matrix S, 3 eigenvalues from det(S − λI) = 0, 4 eigenvectors from (S − λI)U = 0, 5 project the centred data on u₁.
