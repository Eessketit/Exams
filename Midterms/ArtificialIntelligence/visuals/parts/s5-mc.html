Question 1 · Lecture 2.1, Polynomial regression

The model h = w₁x + w₂x² + w₃x³ + b is called polynomial regression. Why can it still be trained exactly like linear regression?

  1. a Because x³ is small enough to ignore No. x³ grows fastest of the three features. It stays in the model as its own column.
  2. b Because gradient descent works for any function No. Gradient descent alone gives no normal equation. Both methods apply here because h is linear in w.
  3. c Because the model is linear in the parameters w; only the features x, x², x³ are non-linear Correct. Slide 46 constructs new features x², x³ and trains a standard linear regression on them.
  4. d Because polynomial regression always has exactly one feature No. There is one input x, but the model uses three features x, x², x³.

Answer: c. The core trick on slide 46 is to construct new features x² and x³ from the input x and train a standard linear regression on them. h is a weighted sum of the columns of X = [1, x, x², x³], so it is still linear with respect to the parameters w and b.

That is why the gradient descent update and the normal equation θ = (XᵀX)⁻¹Xᵀy apply unchanged. The word polynomial describes only the shape of the features in x.

Exam line

Polynomial regression constructs new features x², x³ from x and trains a standard linear regression on them. The model is still linear with respect to the parameters w, so the GD update and the normal equation apply with X columns [1, x, x², x³].

Question 2 · Lecture 2.2, Decision boundary

Logistic regression has hθ(x) = g(θ₀ + θ₁x₁ + θ₂x₂) with θ = [−3, 1, 1]ᵀ. What is its decision boundary?

  1. a The line x₁ + x₂ = 3 Correct. −3 + x₁ + x₂ = 0 gives x₁ + x₂ = 3. On this line h = g(0) = 0.5.
  2. b The line x₁ + x₂ = 0.5 No. This puts the 0.5 threshold on x₁ + x₂. The 0.5 belongs to h. On x₁ + x₂ = 0.5, z = −2.5 and h = 0.076.
  3. c The line x₁ + x₂ = −3 No. That flips the sign of θ₀. On x₁ + x₂ = −3, z = −6 and h = 0.0025.
  4. d The circle x₁² + x₂² = 3 No. A circle needs the features x₁² and x₂². With only x₁ and x₂, θᵀx = 0 is always a straight line.

Answer: a. g(z) ≥ 0.5 exactly when z ≥ 0 (slide 12). So the model predicts y = 1 when −3 + x₁ + x₂ ≥ 0, which is x₁ + x₂ ≥ 3. The boundary is θᵀx = 0, the line x₁ + x₂ = 3, and on it h = 0.5.

Option b confuses the threshold on h with the threshold on θᵀx. Option d would need the polynomial features x₁² and x₂² of slide 42.

Exam line

Predict y = 1 when θᵀx ≥ 0, because g(z) ≥ 0.5 exactly when z ≥ 0. The decision boundary is θᵀx = 0. For θ = [−3, 1, 1]ᵀ it is the line x₁ + x₂ = 3, where h = 0.5.

Question 3 · Lecture 3.1, Precision and recall

A cancer screening test is evaluated. Which error is the most dangerous, and which metric should be prioritised?

  1. a False positive; precision No. A false positive is a false alarm that costs an extra test. Precision is the metric for costly false positives, as in spam detection.
  2. b True negative; accuracy No. A true negative is a correct result, a healthy patient cleared. Accuracy also hides missed cancers when most patients are healthy.
  3. c False positive; accuracy No. The false alarm is the cheaper error here, and accuracy counts both errors the same.
  4. d False negative; recall Correct. A missed cancer can be fatal. Recall = TP/(TP + FN) counts how many real cancers were caught.

Answer: d. A false negative tells a patient who has cancer that they are healthy. That missed cancer can be fatal, while a false positive only costs an extra test.

Recall = TP / (TP + FN) answers the slide question "Of all the real positives out there, how many did the model actually catch?" It is the metric to prioritise when a false negative is dangerous, so doctors accept lower precision for higher recall.

Exam line

Recall (sensitivity) = TP / (TP + FN) answers how many of the real positives the model caught. Prioritise it when a false negative is dangerous, as in cancer screening and airport security. Prioritise precision when a false positive is costly, as in spam detection.

Question 4 · Lecture 3.2 and 5.2, KNN and feature scaling

A KNN classifier uses two raw features: age (20 to 60 years) and salary (40,000 to 80,000). What goes wrong without feature scaling?

  1. a KNN cannot compute distances on integers No. Euclidean distance works on any numbers, integers included.
  2. b The distances are dominated by salary, so age has almost no influence on which neighbours are nearest Correct. A salary gap of 1,000 outweighs an age gap of 20 years.
  3. c The value of k must then be larger than the number of points No. k can never exceed the number of training points. Scaling changes the distances and leaves k alone.
  4. d Nothing; KNN is scale-invariant like a decision tree No. Decision trees are scale-invariant. KNN predicts from distances, and distances depend on the units.

Answer: b. KNN ranks neighbours by the Euclidean distance √(Δage² + Δsalary²). A difference of 1,000 in salary outweighs a difference of 20 years in age, so the salary term decides which neighbours are nearest.

Features on very different ranges are implicitly weighted unequally. Scale first. Slide 19 lists Min-Max as best for neural networks, KNN and SVM.

Exam line

Features on very different ranges (age in years vs income in dollars) get implicitly weighted unequally, and the large-range feature dominates the distance. Scale before KNN. Min-Max is best for neural networks, KNN and SVM. Decision trees are scale-invariant.

Question 5 · Lecture 4.1, Entropy

A decision-tree node holds 3 "Yes" and 1 "No" examples. Its entropy (log base 2) is approximately:

  1. a 0.25 No. 0.25 is p(No) = 1/4 itself, without the log.
  2. b 0.5 No. 0.5 is only the No term, −(1/4) log₂(1/4). The Yes term 0.311 is missing.
  3. c 0.811 Correct. 0.311 + 0.5 = 0.811.
  4. d 1.0 No. 1.0 is the entropy of a 50/50 node, such as 2 Yes and 2 No.

Answer: c. The node has p(Yes) = 3/4 and p(No) = 1/4. E = −(3/4) log₂(3/4) − (1/4) log₂(1/4) = 0.311 + 0.5 = 0.811.

A pure node has entropy 0 and a 50/50 node has entropy 1, so a 3:1 node lies in between. Lower entropy means a purer node.

Exam line

E(S) = −p₍₊₎ log₂ p₍₊₎ − p₍₋₎ log₂ p₍₋₎. A pure node has E = 0 and a 50/50 node has E = 1. A 3 Yes / 1 No node has E = 0.311 + 0.5 = 0.811. Higher entropy means lower purity.

Question 6 · Lecture 4.2, Soft margin

In a soft-margin SVM, a training point has y = +1 and w·x + b = 0.5. What is its slack ζ = max(0, 1 − y(w·x + b))?

  1. a 0.5 Correct. ζ = max(0, 1 − 1 × 0.5) = 0.5. The point is on the correct side but inside the margin.
  2. b 0 No. ζ = 0 needs y(w·x + b) ≥ 1, a point on or beyond its margin line.
  3. c 1.5 No. ζ = 1.5 belongs to a misclassified point with y(w·x + b) = −0.5.
  4. d −0.5 No. The max with 0 means ζ is never negative.

Answer: a. ζ = max(0, 1 − y(w·x + b)) = max(0, 1 − 1 × 0.5) = 0.5.

w·x + b = 0.5 is positive, so the point is on the correct side of the hyperplane. It has not reached its margin line w·x + b = 1, so it sits inside the margin, where 0 < ζ ≤ 1. ζ = 0 is for a point on or beyond its margin line, and ζ > 1 means misclassified.

Exam line

ζ = max(0, 1 − y(wᵀx + b)). ζ = 0 on or beyond the own margin line, 0 < ζ ≤ 1 inside the margin on the correct side, ζ > 1 misclassified. ζ is never negative.

Question 7 · Lecture 5.2, Outliers and standardization

A feature has mean μ = 50 and standard deviation σ = 10. What is the z-score of x = 70, and is it an outlier by the |z| > 3 rule?

  1. a 0.2; no No. 0.2 = 20/100 divides by the variance σ² = 100 instead of σ = 10.
  2. b 20; yes No. 20 is only x − μ. It still has to be divided by σ.
  3. c 3.5; yes No. z = 3.5 belongs to x = 85, which would be flagged.
  4. d 2; no Correct. z = (70 − 50)/10 = 2, and |2| is below the cutoff 3.

Answer: d. z = (x − μ)/σ = (70 − 50)/10 = 2, so the value is 2 standard deviations above the mean. The rule flags |z| > 3, and 2 is below the cutoff, so x = 70 is not an outlier.

The same formula is the standardization scaler, which gives the feature mean 0 and std 1.

Exam line

z = (x − μ)/σ, and |z| > 3 is the common outlier cutoff. For μ = 50, σ = 10, x = 70 gives z = 2, not an outlier. Standardization uses the same formula and gives mean 0, std 1.

Question 8 · Lecture 6.1, K-Means initialization

Running K-Means several times on the same data gives different clusters each time. What causes this, and what does the lecture suggest?

  1. a The data has missing values; impute them No. Missing values are a data-cleaning problem. They do not make one run differ from the next.
  2. b The initial centroids are chosen at random; use K-Means++ to choose them Correct. Slide 19 names random initialization and suggests K-Means++.
  3. c K is too large; always use K = 2 No. K is chosen with the elbow method. With any fixed K, random starts can still differ.
  4. d The distance is Euclidean; use Manhattan No. Changing the distance keeps the random start, so runs still differ.

Answer: b. K-Means starts from K random centroids and then only improves them step by step, so a bad start can end in a bad local minimum. Slide 19 says random initialization "is also potentially problematic because we might get different clusters every time" and suggests K-Means++.

K-Means++ picks the first centroid at random and every next one with probability proportional to D(x)², which spreads the starting centroids. In the course notebook, random seed 42 ends at cost 8979.85, while K-Means++ reaches 611.62 on the same data.

Exam line

Random initialization is potentially problematic because we might get different clusters every time. K-Means++ chooses the first centroid at random and each next one with probability proportional to D(x)², which gives better clusters and faster convergence.

Question 9 · Lecture 5.2, Class imbalance

A fraud dataset has 9,980 normal and 20 fraud transactions. A model that always predicts "Normal" has:

  1. a accuracy 0.2% and recall 100% No. 0.2% is the share of fraud in the data. A model that never says fraud has recall 0.
  2. b accuracy 50% and recall 50% No. The model is right on every one of the 9,980 normal transactions.
  3. c accuracy 99.8% and fraud recall 0 Correct. 9,980/10,000 = 99.8%, and 0 of the 20 frauds are caught.
  4. d accuracy 99.8% and fraud recall 99.8% No. 99.8% is the accuracy. Recall looks only at the 20 frauds, and none are caught.

Answer: c. The model is right on all 9,980 normal transactions and wrong on all 20 frauds. Accuracy = 9,980 / 10,000 = 99.8%. Fraud recall = TP / (TP + FN) = 0 / 20 = 0.

On imbalanced data accuracy is misleading. Use precision, recall, F1 or PR-AUC, a stratified split, and SMOTE or class weights on the training data.

Exam line

On imbalanced data accuracy is misleading. Always predicting Normal on 9,980 normal and 20 fraud gives accuracy 99.8% and fraud recall 0/20 = 0. Evaluate with precision, recall, F1 or PR-AUC, and apply SMOTE only to the training data.

Question 10 · Lecture 6.2, PCA

A 2D dataset has covariance-matrix eigenvalues λ₁ = 30.38 and λ₂ = 6.62. What share of the total variance does the first principal component keep?

  1. a About 82% Correct. 30.38 / (30.38 + 6.62) = 30.38 / 37 = 0.821.
  2. b About 18% No. 18% is 6.62 / 37, the share of PC2.
  3. c 50% No. 50% would need λ₁ = λ₂. Here λ₁ is more than four times λ₂.
  4. d 100% No. 100% means keeping both components. Dropping PC2 loses its 6.62.

Answer: a. Each eigenvalue is the variance of the data along its principal direction. The total is λ₁ + λ₂ = 30.38 + 6.62 = 37, so PC1 keeps 30.38 / 37 = 0.821, about 82%.

These are the eigenvalues of the slide 17 example, where Cov(X₁, X₁) = 14 and Cov(X₂, X₂) = 23 also add up to 37. Reducing that dataset to PC1 keeps about 82% of the information, and PC2 holds the other 18%.

Exam line

Each eigenvalue of the covariance matrix is the variance along its principal direction. PC1 keeps λ₁ / (λ₁ + λ₂) = 30.38 / 37 = 82% of the variance, and most of the information is squeezed into the first components.
